B.1 Introduction

1.1. Example algorithm: 1. Boil water. 2. Put a tea bag in a cup. 3. Pour the water into the cup. 4. Wait three minutes. 5. Remove the tea bag. An algorithm is a list of steps that solves a problem, independent of any language; a program is the translation of an algorithm into code a computer understands.

1.2. An interpreter translates and executes the code line by line, as it reads it. A compiler first translates the whole program and only then executes it. Python (the interpreter) works line by line.

1.3. Results: 6, 2.0 (a division always gives a float), 'HelloHelloHello', 'Hello', 11.5.

B.2 Data Types

2.1. 42 int; 3.14 float; "42" str (it is in quotes); 'hello' str; -8 int; 7.0 float (it has a decimal point); "7.5" str.

2.2. type(42) shows <class 'int'>, type(3.14) shows <class 'float'>, and type("42") shows <class 'str'>: the quotes make it text, even if it looks like a number.

2.3. 8 + 2 gives 10 (two integers are added); "8" + "2" gives '82' (two strings are joined). The quotes change the data type, so they change the operation.

B.7 Conditionals

7.1.

number = int(input("Give me a number: "))
if number > 0:
    print("positive")

7.2.

number = int(input("Give me a number: "))
if number % 2 == 0:
    print("even")
else:
    print("odd")

7.3.

score = int(input("Your score: "))
if score >= 16:
    print("Excellent")
elif score >= 10:
    print("Pass")
else:
    print("Fail")

7.4. Script 1 prints done (the last line is not part of the if, so it always runs). Script 2 prints nothing, because both prints belong to the if and 5 > 10 is false.

7.5.

password = input("Password: ")
if password == "python":
    print("Welcome")
else:
    print("Access denied")

B.8 While Loop

8.1.

i = 1
while i <= 5:
    print(i)
    i += 1

8.2.

i = 10
while i >= 1:
    print(i)
    i -= 1
print("Liftoff!")

8.3. It prints 1, 2, 4, 8 and 16, one per line. Then i becomes 32, which is not smaller than 20, so the loop stops.

8.4.

password = input("Password: ")
while password != "python":
    print("Wrong password")
    password = input("Password: ")
print("Welcome")

8.5.

total = 0
x = input("Give me a number or write stop: ")
while x != "stop":
    total += int(x)
    x = input("Give me a number or write stop: ")
print(total)

8.6. The change part is missing: i never changes, so i < 5 stays true forever. Fix it by adding i += 1 (indented) at the end of the loop body.
