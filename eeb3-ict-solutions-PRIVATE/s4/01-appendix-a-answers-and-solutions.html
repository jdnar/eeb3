A.1 Answers to the questions of the theory

Chapter 1: first use

Hello (without quotes) gives an error because Python looks for a variable called Hello that does not exist. "Hello" is text. 7 is an integer, 9.5 + 2 gives 11.5, 2 * 3 gives 6, 10 / 5 gives 2.0 (a division always returns a float), "Hello" * 10 repeats the word ten times and "He" + "llo" joins the two pieces into 'Hello'.

Chapter 3: variables

Question 1. The first time, age + 2 only calculates and displays 16: the result is not saved anywhere, so age is still 14. With age = age + 2 the result is assigned back to the variable, so age now holds 16.

Question 2. "age" * 2 is a string multiplied by 2, which repeats the text: the result is 'ageage'. That text is then assigned to the variable age, replacing the number it held before.

A.6 Projects

# project1
import random

number = random.randint(1, 10)
guess = 3
found = False

while found == False and guess > 0:
    user_number = int(input("Guess a number between 1 and 10: "))
    if user_number == number:
        print("Congratulations, you found the number!")
        found = True
    else:
        print("Wrong answer")
        guess = guess - 1

if found == False:
    print("You have no guesses left. The number was", number)

# project2
import random

play = True

while play == True:
    door = random.randint(1, 3)
    choice = int(input("Which door do you open? (1, 2 or 3) "))

    if choice == door:
        print("You found the treasure! You are rich!")
    else:
        print("Oh no... behind this door there were starving tigers!")
        print("The treasure was behind door", door)

    answer = input("Do you want to play again? (yes/no) ")
    if answer != "yes":
        play = False

print("Thanks for playing!")

# project3
import random

moves = ["rock", "paper", "scissors"]
player_score = 0
computer_score = 0
play = True

while play == True:
    computer = random.choice(moves)
    player = input("Rock, paper or scissors? ").lower()

    if player not in moves:
        print("Please type rock, paper or scissors.")
    else:
        print("The computer chose", computer)
        if player == computer:
            print("It's a draw!")
        elif (player == "rock" and computer == "scissors") or (player == "scissors" and computer == "paper") or (player == "paper" and computer == "rock"):
            print("You win!")
            player_score += 1
        else:
            print("The computer wins!")
            computer_score += 1
        print("Score - You:", player_score, "Computer:", computer_score)

    answer = input("Play again? (yes/no) ")
    if answer != "yes":
        play = False

print("Final score - You:", player_score, "Computer:", computer_score)
Note: Exercise 9 prints 0 to 100 with i <= 100; Exercise 12 does the same with range(101) because the end value of range is not included. Exercises 10 and 13 both give 15150.
Note: In the projects, the numbers and moves are random, so your program will behave differently each time you run it. Run it several times to check every case (win, lose, play again).
