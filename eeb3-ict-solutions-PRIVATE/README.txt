EEB3 ICT - PRIVATE SOLUTIONS
===========================

This folder contains the solutions to all the exercises of the public course.
It is for the teacher only.

IMPORTANT
- Do NOT upload this folder to the public repository or to the public website.
  Anything that is uploaded to a public GitHub Pages site (or any public web server)
  can be read by anyone who has the address.
- To use it, just open index.html with a double click (it works offline, no server needed).
- Keep it on your computer, on a USB drive, or in a PRIVATE repository.
  (If you want to read it online from a private repository, GitHub Pages for private
  repositories needs a paid plan; otherwise keep it local.)
- Pages already include a "noindex" tag so search engines are asked to ignore them,
  but that does NOT make them private by itself.

Contents
- s4/ : answers and solutions for Python S4 (exercises 1-15, projects, warm-ups)
- s5/ : answers and solutions for Python S5 (exercises 1-18, Hangman, warm-ups)
        and the solutions of the Functions Practice sheet (46 exercises + 5 mini-projects)
