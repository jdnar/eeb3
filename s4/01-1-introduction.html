1. Introduction

On this page
  • 1.1 Some definitions
  • 1.2 Tools
  • 1.3 First use

Python is a popular programming language first created by Guido van Rossum in 1991 and named after the British comedy group Monty Python. It is widely used, including by famous companies and organizations such as Google, YouTube, BitTorrent, Intel, Cisco, Hewlett-Packard, NASA and iRobot.

1.1 Some definitions

TermMeaning
AlgorithmA process, or list of steps, to follow in order to solve a particular problem. An algorithm can be implemented on a computer.
ProgramA set of instructions which, when executed on a computer, performs a defined process. A program is the translation into computer-understandable code of an algorithm that solves a problem.
Programming languageA language such as Python that defines the rules a program must respect to be understood and executed by a computer.
Interpreter vs compilerA program called an interpreter or a compiler "translates" the programming language into machine code. Python uses an interpreter: your code is read, translated and executed line by line. C++ uses a compiler: the whole code is first translated and only then executed.

1.2 Tools

Two tools are essential:

  • a Python 3 interpreter (the >>> prompt), which lets you run your code on your computer;
  • a text editor to type and save your programs.

The software used in this course is the Thonny IDE. Thonny comes with Python built in, so a single installer is all you need. To install it at home, download the latest version from https://thonny.org/ and install it like any other application.

1.3 First use

Let us test the interpreter. The prompt >>> means the interpreter is ready to receive your instructions. Programming languages follow a very specific syntax: if you type random things, or do not respect the syntax, Python returns an error.

Exercise. In the Thonny shell (or in any online Python interpreter), type each of the following lines and observe the results:

  • Hello
  • "Hello"
  • 7
  • 9.5 + 2
  • 2 * 3
  • 10 / 5
  • "Hello" * 10
  • "He" + "llo"
Note: The first line gives an error because Python reads Hello as the name of a variable that does not exist. The same word between quotes is a piece of text. You will see why in the next chapters.
