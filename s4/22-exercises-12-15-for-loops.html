Exercise 12 — exercise12

Write a program that prints the values from 0 to 100 using a for loop.

Tip: Go back to the first example of range in Chapter 9. Remember that the end value is not included.

Exercise 13 — exercise13

Write a program that sums the numbers between 100 and 200 (both included) using a for loop, and prints the final result.

  • Initialise a variable total to 0.
  • Use a for with range to create a sequence going from 100 to 200 included (see range(4, 8) in Chapter 9).
  • Inside the loop, add the iterator to total.

Exercise 14 — exercise14

Write a program that prints the multiplication table of 3 using a loop (for or while, as you prefer).

Tip: Use a for with range to create a sequence going from 1 to 10 included. Print the calculation and the result: print(iterator, " * ", 3, " = ", iterator * 3).
