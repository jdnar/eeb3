Warm-up 1: Introduction

On this page
  • Step 1.1 — Algorithm vs program
  • Step 1.2 — Interpreter or compiler?
  • Step 1.3 — First use: predict, then check

Three thinking steps on the vocabulary of Chapter 1, plus your first interpreter predictions.

Tip: Do each step yourself before looking at the answer. Solutions: Appendix B.1.

Step 1.1 — Algorithm vs program

Write, in plain English, an algorithm (a numbered list of steps) to make a cup of tea. Then explain in one sentence the difference between an algorithm and a program.

Step 1.2 — Interpreter or compiler?

Python uses an interpreter and C++ uses a compiler. In your own words, what is the difference? Which of the two reads, translates and executes your code line by line?

Step 1.3 — First use: predict, then check

Predict the result of each line, then type it in the Thonny shell: 2 * 3, 10 / 5, "Hello" * 3, "He" + "llo", 9.5 + 2.
