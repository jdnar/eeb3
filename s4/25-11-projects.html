Project 1 — project1: Guess the number

Write a program asking the user to find a number between 1 and 10. The user can have up to three guesses. Your program should:

  • randomly select a number between 1 and 10 and save it in a variable;
  • create a loop with two conditions: the user still has guesses left and has not found the correct answer yet.

Inside the loop, it should ask the user for their guess with input, then check with a conditional whether the guess is correct. If it is, congratulate the user and get out of the loop; if not, remove one guess.

Help

  • Create a variable number with a random number between 1 and 10: the number to guess.
  • Create a variable guess set to 3. Decrease it by one each time the user gives a wrong number.
  • Create a variable found set to False. Change it to True when the user finds the right number.
  • Write your while loop with the two conditions: found == False and guess > 0.
  • Ask for a number between 1 and 10 and save the answer in user_number.
  • Compare number and user_number: if they are the same, congratulate the user and set found to True; otherwise decrease guess by 1.

Project 2 — project2: Three doors

Write a program that asks the user to choose between three doors. Behind two doors there are starving tigers; behind one door there is a treasure. The user has to guess the door hiding the treasure, and must be able to play again. Your program should create a loop with the condition "the user wants to play". Inside the loop, it should:

  • randomly select a number between 1 and 3;
  • ask the user for their guess with input;
  • check with a conditional whether the guess is correct and print an appropriate message;
  • ask the user whether they want to play again.

Help

  • Initialise a variable play to True. If the user does not want to play any more, change it to False.
  • Write a loop whose condition is play == True.
  • Create a variable door and randomly assign it a number between 1 and 3.
  • Ask the user which door they want to open and save the answer in a variable.
  • Write a conditional to check whether the treasure was found and print a message.
  • Ask whether the user wants to play again.

Project 3 — project3: Rock, Paper, Scissors

Code a Rock, Paper, Scissors game. This one is yours to design. Some ideas to get started:

  • The computer picks its move at random with random.choice(["rock", "paper", "scissors"]).
  • The user types their move with input.
  • Compare the two moves with if / elif / else: rock beats scissors, scissors beats paper, paper beats rock; the same move is a draw.
  • Show both moves and announce who won.
  • Let the user play again, and keep a score for each player using a loop.
