Exercise 1 — exercise1

Write a program that uses the variables daysPerWeek, hoursPerDay and minutesPerHour to calculate the number of minutes in a week, and prints the answer.

Tip: To initialise a variable: name = value. Multiply the three variables: minutesPerWeek = daysPerWeek * hoursPerDay * minutesPerHour. Do not forget to print your answer. The answer is 10080.

Exercise 2 — exercise2

Write a program that asks for three integers a, b, c and prints the result of (a + b)² − c. Run it with different inputs and check the results.

Tip: Ask an integer with numberOfChildren = int(input("How many children do you have? ")). In Python, a to the power of b is written a ** b.

Exercise 3 — exercise3

Write a program that asks for two numbers and divides the first by the second. It should print the calculation, the result of the division, the quotient and the remainder. Example:

Output
>>> %Run exercise3.py
Give me a first number: 9
Give me a second number: 4
9 : 4 = 2.25
The quotient of the division is 2
The remainder of the division is 1
>>>

What is the remainder when the first number is divisible by the second one? It is zero: if a is divisible by b, then a % b equals 0.

Tip: To print a mix of text and variables, separate them with commas: print("Your name is", name, "and it's a nice name."). The quotient operator is // and the remainder operator is %.

Exercise 4 — exercise4

Write a program that asks for the name of the user and their favorite food, and prints: The favorite food of x is y (with the real values instead of x and y). Run it with different inputs.

Exercise 5 — exercise5

Write a program that asks for the name and the age of the user. It prints a first message including the name, saying it is a nice name, and a second message including the age saying that you are one year older and showing that age.
