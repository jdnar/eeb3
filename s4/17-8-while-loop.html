8. While Loop

In programming, loops let you execute instructions repetitively. The while loop repeats its instructions as long as a certain condition is true. The syntax is:

while condition:
    instructions

The condition is a boolean expression and the instructions are indented.

8.1 The four parts of a while loop

A typical while statement has four parts: initialisation, condition, processing and change.

initialisation
while condition:
    processing
    change
PartRole
InitialisationWhere you initialise all the variables you need for the loop.
ConditionDefines whether the instructions of the loop body are executed.
ProcessingThe work done in the body of the loop.
ChangeAt the end of the body, modifies the variables used in the condition, so the loop can eventually stop.

A while loop is usually used for two reasons:

  • Processing until a condition is met:
n = "first value"
while n is not equal to the value to stop:
    processing
    n = "new value"
  • Reading a sequence of data:
x = input('First data: ')
while x != 'F':
    processing
    x = input('Next data: ')

8.2 Examples

Example 1: counting

n = 5
i = 0
while i < n:
    print(i)
    i += 1
Output
0
1
2
3
4

The code initialises two variables, n and i (initialisation). Then it checks whether i is smaller than n (condition); if so, it prints i (processing) and adds 1 to i (change). i += 1 is a short way of writing i = i + 1.

Example 2: playing again

n = "yes"
while n == "yes":
    print("This is my game.")
    print("My game is now over.")
    n = input("Do you want to play again? (yes/no)")

The variable n starts at "yes" (initialisation). While n equals "yes" (condition), two messages are printed (processing) and the user is asked whether to play again (change).

Example 3: adding numbers until "stop"

total = 0
x = input("Give me a number or write stop: ")
while x != "stop":
    total += int(x)
    x = input("Give me a number or write stop: ")
print(total)

This code adds together the numbers given by the user and then prints the result. It first initialises total and x. As long as x is not the word "stop", it adds the number to total (processing) and asks for another number (change). Once the user writes stop, the loop ends and the total is printed.

Important: The print(total) is executed only once, at the end, because it is not indented: it is not part of the while.
Important: You do not know whether the user will give a number or the word stop. So first read the answer as a string and, only if it is not stop, convert it with int(x).
Watch out: if you forget the change part, the condition never becomes false and the program loops forever (an infinite loop). In Thonny, press the red Stop button to interrupt it.
