9. For Loop

The while loop repeats its instructions while a condition is true. The for loop repeats them for each item of a sequence, that is, a specific number of times. A for loop is used to iterate over a sequence and execute the same set of instructions for each item. The syntax is:

for iterator in sequence:
    instructions

The iterator is a variable that exists only inside the loop; the sequence is a string, a list, a tuple, a dictionary or a set (you will meet these in the next course); the instructions are indented.

Tip: Choose a meaningful name for the iterator: letter if you go through a word, name if you go through a list of names.

9.1 Examples

Example 1: going through a word

for letter in "banana":
    print(letter)
Output
b
a
n
a
n
a

The loop goes through the word and prints each letter.

Example 2: going through a list

for name in ["Antoine", "Julie", "Quentin", "Alice"]:
    print("hello")
Output
hello
hello
hello
hello

The loop goes through a list of four names and prints hello each time (the iterator name is not used here).

Example 3: counting the items

count = 0
for name in ["Antoine", "Julie", "Quentin", "Alice"]:
    count += 1
print(count)
Output
4

The variable count starts at 0. For each name in the list, 1 is added to count. After the loop, the value is printed.

9.2 The range() function

To loop a specified number of times, use the range() function as the sequence. range() returns a sequence of numbers. By default it starts from 0, increases by 1 and ends at the specified number minus 1 (the end is not included).

Example 4: summing numbers

total = 0
for val in range(6):
    total += val
print(total)

This code adds all the numbers between 0 and 5 and prints the result: 15.

Example 5: a pyramid of #

for number in range(8):
    print("#" * (number + 1))
Output
#
##
###
####
#####
######
#######
########

This code prints a pyramid of #, starting with 1 and ending with 8. Multiplying a string by a number repeats it.

Use while when…Use for when…
you do not know in advance how many times to repeat (until the user types stop, until a condition changes).you know how many times to repeat, or you want to go through every item of a sequence.
