Small scripts using print() and input(). Save each one as a .py file and run it.

Tip: Do each step yourself before looking at the answer. Solutions: Appendix B.5.

Step 5.1 — Print a message

Write a script that prints Hello, world!.

Expected output:

Output
Hello, world!

Step 5.2 — Print variables

Create name = "Ana" and age = 15, then print the sentence below using commas in a single print.

Expected output:

Output
My name is Ana and I am 15 years old.

Step 5.3 — Ask a name

Ask the user their name with input and print Hello, followed by the name and !. Example run (the user typed Marc):

Expected output:

Output
What is your name? Marc
Hello, Marc!
Tip: Remember that input() always returns a string.

Expected output:

Output
How old are you? 14
Next year you will be 15

Expected output:

Output
Give me a price: 2.5
Double price: 5.0
