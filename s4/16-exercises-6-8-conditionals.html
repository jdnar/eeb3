Exercise 6 — exercise6

Write a program that checks whether the user is more or less than 12 years old. It should ask the user their age; if they are older than 12, print You are getting old...; otherwise print You are a child. Run it with different inputs.

Tip: Define a variable age and read an integer: variable_name = int(input("question")). Then write an if / else with age > 12 as the condition and a print("message") in each block.

Exercise 7 — exercise7

Write a program acting like a thermostat. It should ask the current temperature, then the ideal temperature, and compare them. If the current temperature is higher, print a message asking to decrease the temperature. If it is lower, print a message asking to increase it. If it is the same, print nothing.

Tip: Use two variables, ct (current temperature) and it (ideal temperature), read as floats with float(input("question")). The conditional needs an if, an elif and, if you wish, an else (compare ct and it with >, < or ==).

Exercise 8 — exercise8

Write a program that checks whether you have enough money to buy an item. Ask how much money the user has and the price of the item. If the user has enough, print how much money would be left after the purchase; if not, tell the user how much more money is needed.

Tip: Read two floats: money and item. You can print the result of a calculation directly, or together with a message: print("The result of var1 - var2 is:", var1 - var2). Do not hesitate to test this in the interpreter first.
