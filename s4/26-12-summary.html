12. Summary

On this page

A program is a set of instructions that translates an algorithm into code a computer can execute. Python uses an interpreter: your code is read, translated and executed line by line.

Data types, variables and operators

ConceptSummary
int, float, strWhole numbers, decimal numbers and text. Check with type().
name = valueAssignment: saves a value in a variable. Names use letters, numbers and _, cannot start with a number, and are case sensitive.
+ - * / ** % //Addition, subtraction, multiplication, division (float), power, remainder, truncated quotient.
print(a, b)Shows values on the screen, separated by a space.
input("question")Asks the user; always returns a string. Convert with int() or float().

Decisions

ConceptSummary
== != > < >= <=Comparison operators; they return a boolean (True or False).
and, or, notBoth true / at least one true / the opposite.
if / elif / elseRun a block only when its condition is true; checked in order, one else at the end.
Indentation4 spaces (or one tab) mark the instructions that belong to a block.

Loops and random

ConceptSummary
while condition:Repeats while the condition is true. Four parts: initialisation, condition, processing, change.
for item in sequence:Repeats for each item of a sequence (string, list…).
range(stop), range(start, stop), range(start, stop, step)Sequence of numbers; the stop value is not included.
import randomrandom.randint(a, b) integer (both included); random.uniform(a, b) float; random.choice(seq) one item.

Common mistakes to avoid

  • Using = (assignment) instead of == (comparison).
  • Forgetting that input() returns text: "3" + "4" is "34", not 7.
  • Forgetting the colon : at the end of if, elif, else, while and for lines, or forgetting the indentation.
  • Forgetting the change part of a while loop (infinite loop).
  • Expecting range(5) to include 5: it stops at 4.
