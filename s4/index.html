How to Use This Course

On this page
  • Course map
  • Tools you need
  • Good habits

This course takes you from your very first line of Python to small complete programs. You will learn what a program is, how to store data in variables, how to talk to the user with input and output, how to make decisions with conditionals and how to repeat actions with loops. It ends with three small games.

Every chapter has the same rhythm: short theory with runnable examples, a warm-up with very easy steps (one per idea of the theory), and then the main exercises or projects. Solutions are collected in the appendices — try each step yourself first.

Tools you need

  • A computer and the Thonny editor (free, from https://thonny.org/), which includes Python. Any other Python editor works too.
  • A folder called Python where you save every exercise with the name given (exercise1, exercise2, …).

Good habits

  • Type every example yourself instead of copying it, and run it after each change.
  • Read the error messages: they tell you the line and the kind of mistake.
  • The lines >>> %Run exercise.py in the sample outputs are what Thonny prints when you run a script; your program should produce the lines that follow.
  • When you are stuck, re-read the theory of the chapter, then the Help boxes, and only then look at the solution.
Important: There are many correct ways to solve a programming problem. Your solution does not need to be identical to the one in the appendix: it needs to give the expected result.
