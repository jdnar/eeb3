2. Data Types

Data is a basic element of programming: it can be numbers or letters. Every piece of data has a specific type:

TypeMeaningExamples
intInteger: a whole number1, 8, -25
floatA decimal number1.2, 7.8
strString: a text'Hello', "Hello", '"Hello"'

There are more data types, which you will meet in the next course. You can ask Python the type of any value with the function type():

>>> type(8)
<class 'int'>
>>> type(1.2)
<class 'float'>
>>> type("Hello")
<class 'str'>
Note: A string is delimited by quotes. You can use single quotes '...' or double quotes "..."; to put quotes inside a string, use the other kind around it, as in '"Hello"'. The number 8 and the string "8" are different things for Python.
