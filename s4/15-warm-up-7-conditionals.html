One tiny program for each form of the conditional statement.

Tip: Do each step yourself before looking at the answer. Solutions: Appendix B.7.

Step 7.1 — Simple if

Ask a number. If it is greater than 0, print positive. Example (the user typed 5):

Expected output:

Output

positive

Step 7.2 — if / else

Ask a number and print even or odd. Example (the user typed 8):

Expected output:

Output
Give me a number: 8
even
Tip: A number is even when number % 2 == 0.

Step 7.3 — if / elif / else

Ask a score. Print Excellent if it is 16 or more, Pass if it is 10 or more, and Fail otherwise. Example (the user typed 12):

Expected output:

Output
Your score: 12
Pass

Step 7.4 — Indentation: predict

With x = 5, what does each of these two scripts print?

# Script 1
x = 5
if x > 10:
    print("big")
print("done")

# Script 2
x = 5
if x > 10:
    print("big")
    print("done")
