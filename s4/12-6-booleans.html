6. Booleans

On this page
  • 6.1 Comparison operators
  • 6.2 AND, OR, NOT
  • 6.3 Exercise: guess the result

Let us focus on a new data type: the boolean. A boolean has only two possible values: True or False. In Python they are written with a capital first letter and without quotes.

6.1 Comparison operators

OperatorMeaningExample
==Equal to5 == 5 is True
!=Different froma != 3
>Greater thana > 8
<Less thana < 15
>=Greater than or equal to2 >= 2 is True
<=Less than or equal to3 <= 2 is False

When you use a comparison operator, Python returns a boolean: the result of the comparison is either True or False.

>>> 5 == 5
True
>>> 5 == 6
False
>>> a = 0
>>> a > 8
False
>>> a != 3
True
>>> a < 15
True
Important: One = versus two ==: the single = assigns a value to a variable; the double == compares two values.

6.2 AND, OR, NOT

  • Use and to test whether both conditions are true.
  • Use or to test whether at least one of the two conditions is true.
  • Use not to test whether the opposite of a condition is true.

and

>>> a = 3
>>> b = 6
>>> a < b and a > 0
True
>>> a > b and a > 0
False
>>> a > b and a < 0
False
>>> a < b and a < 0
False

and returns True only if both conditions are True.

or

>>> a < b or a > 0
True
>>> a > b or a > 0
True
>>> a > b or a < 0
False
>>> a < b or a < 0
True

or returns True if one or both conditions are True.

not

>>> not a < b
False
>>> not b < a
True

not returns True if the condition is False, and False if the condition is True.

6.3 Exercise: guess the result

Try to guess each time whether the condition will be True or False, then check in the interpreter (answers: Appendix A.1).

  1. 1 == 1
  2. "hello" == "bye"
  3. 2 != 8
  4. 3 > 8 and 2 > 3
  5. 2 < 5 or 5 > 10
  6. "hello" != "world" and 3 >= 2
  7. not 3 > 5
  8. not (2 == 2 and 3 != 4)
  9. 2 >= 2 or (5 < 4 and 3 > 1)
