7. Conditionals

On this page
  • 7.1 if
  • 7.2 elif
  • 7.3 else
  • 7.4 Examples
  • 7.5 Indentation matters

Conditionals let you execute instructions only if a certain condition is true.

7.1 if

Its simplest form is:

if condition:
    instructions

The condition can be, for example, a comparison between two values (see Chapter 6).

Important: Indentation. The block of instructions is moved to the right by 4 spaces (or one tab). This is called indentation, and it is how Python identifies the instructions that must be executed when the condition is true.

7.2 elif

Sometimes you want to test a condition and, if it is false, test another one — and so on. You can add as many elif as you want:

if condition:
    instructions
elif condition:
    instructions
elif condition:
    instructions
...

7.3 else

Finally, to select all the cases where none of the conditions above is true, use else. You can add only one else, at the very end of the conditional statement. It needs no condition: it covers the opposite of all the previous conditions.

if condition:
    instructions
elif condition:
    instructions
...
else:
    instructions

7.4 Examples

A simple example

age = int(input("Give me your age: "))
if age >= 18:
    print("You are an adult.")

The message is printed only if the value saved in age respects the condition >= 18.

A more complex example

number = int(input("Give me a number: "))
if number < 0:
    print("The number is negative.")
elif number > 5:
    print("The number is higher than 5.")
elif number == 3:
    print("The number is equal to 3.")
else:
    print("The number is not negative, not higher than 5 and not equal to 3.")

If the value is negative, the program says it is negative. Else if it is higher than 5, it says so. Else if it is equal to 3, it says so. If none of those conditions is met, the instruction after else is executed.

Note: Python checks the conditions in order and runs only the first block whose condition is true. With the value 3, the conditions number < 0 and number > 5 are false, so number == 3 is the one that runs.

7.5 Indentation matters

Compare these two scripts:

# Script 1
x = int(input("Give me a number: "))
if x > 0:
    print("The value is strictly positive.")
print("Goodbye")
# Script 2
x = int(input("Give me a number: "))
if x > 0:
    print("The value is strictly positive.")
    print("Goodbye")

In Script 1, Goodbye is printed every time, whatever the value of x. In Script 2, print("Goodbye") is indented, so it belongs to the if and is printed only if x is greater than 0.
