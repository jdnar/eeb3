5. Script, Input & Output

On this page
  • 5.1 Script
  • 5.2 Output: print()
  • 5.3 Input: input()

Until now we have interacted directly with the Python interpreter. You can keep using it from time to time to test some specific code, but from now on we will program in the text editor and only then run the program in the interpreter.

5.1 Script

Let us create a script that calculates the perimeter and the area of a rectangle from its length and width.

  1. Open Thonny.
  2. Write the code below in the script window (the upper part, above the interpreter).
length = 5
width = 3
perimeter = 2 * width + 2 * length
area = width * length
(area, perimeter)
  1. Save your file and name it rectangle.py.
  2. Open the Run menu and click Run current script. The interpreter shows:
Output
>>> %Run rectangle.py
>>>

There is no error: everything worked. But there is also no result.

Question. Why do we not see any result? Should we not see the perimeter and the area of the rectangle?

Answer. As soon as we use scripts, if we want to communicate with the user and show results on the screen, we need an output function: print().

5.2 Output: print()

The print() function shows on the screen whatever is written between the parentheses. Let us improve the script.

  1. Update your code: just add print at the beginning of the last line.
length = 5
width = 3
perimeter = 2 * width + 2 * length
area = width * length
print(area, perimeter)
  1. Run the current script again. The interpreter now shows:
Output
>>> %Run rectangle.py
15 16
>>>
  1. Add some text in the print so the message is clearer:
length = 5
width = 3
perimeter = 2 * width + 2 * length
area = width * length
print("Area:", area, "Perimeter:", perimeter)
Output
Area: 15 Perimeter: 16

You can now easily share information with the user. Items separated by commas in print are displayed separated by a space.

Question. What if we want the user to choose the length and the width of the rectangle?

Answer. If we want the user to give information to the computer, we need an input function: input().

5.3 Input: input()

The function input() lets your script ask a question to the user. It interrupts the execution of the program and waits for the user's answer. You can then save the answer in a variable and reuse it later. input() accepts one optional parameter: the message shown to the user.

Important: The data returned by input() is always a string. If you want an integer or a float, you have to convert it with int() or float().
Type wantedExample
IntegernumberOfChildren = int(input("How many children do you have? "))
Floattemperature = float(input("What is the temperature? "))
Stringname = input("What is your name? ")

Let us improve the rectangle script by asking the width and the length to the user. Add the input on the right side of the = for length and width:

length = float(input("Give me a length: "))
width = float(input("Give me a width: "))
perimeter = 2 * width + 2 * length
area = width * length
print("Area:", area, "Perimeter:", perimeter)

Run it. The interpreter shows (the user typed 8 and 9):

Output
>>> %Run rectangle.py
Give me a length: 8
Give me a width: 9
Area: 72.0 Perimeter: 34.0
>>>
