Exercise 9 — exercise9

Write a program that prints the values from 0 to 100 using a while loop.

Tip: Go back to the first example of the while loop in Chapter 8 (counting from 0 to n - 1). Think about which condition makes 100 be printed too.

Exercise 10 — exercise10

Write a program that sums the numbers between 100 and 200 (both included) using a while loop, and prints the final result.

  • Initialisation: a variable count set to 100 and a variable total set to 0.
  • Condition: count is smaller than or equal to 200.
  • Processing: add count to total.
  • Change: increase count by 1.
Note: The expected result is 15150.

Exercise 11 — exercise11

Using input and while, write a program that repeatedly asks the user how they are doing and prints a message, until the user enters stop.

  • Initialisation: set a variable to anything except "stop".
  • Condition: the variable is different from "stop".
  • Processing: print a message.
  • Change: use input to change your variable and ask how the user is doing.
