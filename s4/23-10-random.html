10. Random

In programming, you will sometimes need to select a random number or a random item from a list. To do this we need to import a module called random. Importing a module is easy: write at the very top of your code:

import module_name

Then, depending on what you want to do, you use a different function of the random module:

FunctionWhat it doesExample
randint(a, b)Randomly selects an integer between a and b, both included.random.randint(3, 7)
uniform(a, b)Randomly selects a float between a and b.random.uniform(3, 7)
choice(sequence)Randomly selects one item from a sequence.random.choice(["chocolate", "vanilla", "strawberry"])

randint: a random integer

import random

x = random.randint(3, 7)    # 3, 4, 5, 6 or 7

uniform: a random float

import random

x = random.uniform(3, 7)    # for example 5.381...

choice: a random item

import random

x = random.choice(["chocolate", "vanilla", "strawberry"])
Tip: Because the results are random, your program gives a different output each time you run it. Run it several times to see it.
