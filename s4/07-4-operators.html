4. Operators

On this page
  • 4.1 Modulus %
  • 4.2 Quotient //
  • 4.3 Exercise: observe the results

In Python we use the following arithmetic operators:

OperatorOperationExample
+Addition4 + 17 gives 21
-Subtraction9 - 4 gives 5
*Multiplication2 * 3 gives 6
/Division (always gives a float)10 / 5 gives 2.0
**Power7 ** 3 gives 343
%Modulus (remainder of a division)10 % 4 gives 2
//Quotient (truncated division)18 // 5 gives 3

4.1 Modulus %

The modulus operation finds the remainder after the Euclidean division of one number by another.

Example 1: 10 % 4Example 2: 27 % 16
10 / 4 = 2.5, so the whole part is 227 / 16 = 1.6875, so the whole part is 1
2 × 4 = 81 × 16 = 16
10 − 8 = 227 − 16 = 11
10 % 4 = 227 % 16 = 11
Tip: % is very useful to test divisibility: a % b == 0 means that a is divisible by b.

4.2 Quotient //

The quotient operation keeps only the truncated result of the division (the whole part).

Example 1: 18 // 5Example 2: 12 // 7
18 / 5 = 3.612 / 7 = 1.714…
18 // 5 = 312 // 7 = 1

4.3 Exercise: observe the results

In the interpreter, type the following and observe the results. Try to predict each result before pressing Enter.

>>> 4 + 17
>>> 15 * 90 * 2
>>> 2 * (3 + 4)
>>> 1 + 18 / 4
>>> 7 ** 3
>>> 20 % 17
>>> 20 // 17
>>> 0.09 + 8.3
>>> 7.004 - 9.004
>>> 3.4 % 0.5
>>> 3.4 // 0.5

Results: 21, 2700, 14, 5.5, 343, 3, 1, 8.39, -2.0, 0.3999999999999999, 6.0.

Note: The last results with decimals can look surprising (3.4 % 0.5 gives 0.3999999999999999, not 0.4). Computers store decimal numbers in binary, which makes tiny rounding differences. This is normal and not a mistake in your code. Use round() to display a clean number.
Important: Operators follow the usual order of operations: parentheses first, then powers, then multiplication/division/modulus/quotient, then addition/subtraction.
