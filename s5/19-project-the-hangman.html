Project: The Hangman

On this page
  • Rules
  • Technical side
  • Suggested steps

Rules

The computer chooses a random word of up to eight letters from a file. The player tries to find the letters of the word. At each turn the player chooses a letter. If the letter is in the word, the computer displays the word with the letters already found; letters not yet found are replaced by an underscore _. The player has 8 chances; after that, they lose.

At the beginning of the game, ask the player their name. The player's score is the number of chances remaining when they find the word: if three chances are left, they win three points.

Technical side

Divide your program into at least four functions:

  1. getWord()
  2. addLetter(letter, userWord, word)
  3. displayWord(word)
  4. mainGame()

Feel free to split these into smaller functions: it is your program, and this is just one way to do it. Think before you start; a piece of paper and a pen can help you organize your thoughts.

Suggested steps

  1. Start with getWord(). Randomly select one word from words.txt and print it to make sure it works.
  2. Start mainGame(): initialise all your variables (including word and userWord) and make sure userWord has as many "_" as the word has letters. Print both to check.
  3. Write the loop of mainGame(): ask a letter, add it to alreadyTried if it has not been tried yet, and check whether the letter is in the word. Print specific messages to check that your code works.
  4. Create addLetter(letter, userWord, word): go through the word and, every time the letter appears, replace the _ in userWord at the correct position by the letter. Test it before going further.
  5. Update mainGame() to call addLetter each time the player finds a new letter.
  6. Finish the game: outside of the loop, check whether the player won or lost and print the appropriate message.
  7. When you print the userWord list it does not look nice (['_', 'y', '_']). Code displayWord so it prints something like _ y _.
  8. Make sure you understand everything and that everything works. Then improve your code and add new features (for example, show the letters already tried, keep a best score, or let the player play again).

A reference solution is in Appendix A.7.
