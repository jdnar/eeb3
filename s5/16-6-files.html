6. Files

Sometimes you want your program to get information from a file, or to save information in a file. Whether you read or write, remember the rule: you always start by opening the file and you end by closing it.

To open a file you use the function open, which takes two parameters:

  • the path to the file (put an r in front of the string if it is an absolute path, e.g. r"C:\Users\me\file.txt");
  • the opening mode.
ModeMeaning
"r"Read only.
"w"Write mode. If the file exists, its content is deleted; if it does not exist, it is created.
"a"Append mode. Writes at the end of the file without deleting the previous content; creates the file if it does not exist.

Once a file is open for reading, read() returns its content. Once it is open for writing, write() writes into it. When you are done, close() closes it.

Important: To add content, choose the "a" mode. The "w" mode overwrites the content and you start with an empty file.
Important: Always close your file at the end. A file that stays open is locked, and other programs cannot use it.

Write

my_file = open(r"C:\Python\file.txt", "w")
my_file.write("First time writing in a file using Python!")
my_file.close()

Append

my_file = open(r"C:\Python\file.txt", "a")
my_file.write("Not the first time anymore...")
my_file.close()

Read

my_file = open(r"C:\Python\file.txt", "r")
content = my_file.read()
print(content)    # prints the content of the file
my_file.close()
Note: The paths above are examples (Windows style). Use the real path of your own file, or just the file name if it is in the same folder as your program.
