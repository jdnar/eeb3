Functions

  • Define a function with def name(parameters): and an indented body; return sends a value back.
  • Call it with name(arguments); the call is replaced by the returned value.
  • Variables created inside a function are local to it. A function can print, change data in memory, or return a value.
  • To return several values use return (a, b) and read them with result[0], result[1].
