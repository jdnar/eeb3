4. Split & Join

Lists and strings are different. Sometimes a list is preferable, sometimes a string. Fortunately you can easily transform a string into a list and a list into a string with the methods split and join.

4.1 Split

split converts a string into a list by cutting it at a delimiter. The parameter you give to split decides where the string is cut. Here we cut at every space:

my_text = "Hello World"
my_text = my_text.split(" ")
print(my_text)    # ['Hello', 'World']

4.2 Join

join converts a list into a string. You apply it to a string (the separator) and give the list as parameter. The separator is inserted between every element:

my_list = ["Hello", "World"]
my_list = " ".join(my_list)
print(my_list)    # Hello World
