Exercises: Strings (5–6)

Exercise 5 — exercise5

Write a function concatUpper(a, b) that receives two strings and returns them concatenated and in upper case. Then write a program that asks two different sentences to the user, calls concatUpper with them, and prints the result.

Tip: To concatenate use +; to put a string in upper case use the method .upper().

Exercise 6 — exercise6

Write a function ingly(word) that receives one word:

  • if the word has more than 3 letters and does not end with ing, return the word with ing added at the end;
  • if it has more than 3 letters and already ends with ing, add ly instead;
  • if the word is shorter, return it unchanged.

Then write a program that asks a word, calls ingly, and prints the result. Examples:

Output
Give me a word
play
playing
Output
Give me a word
go
go
Output
Give me a word
string
stringly
Tip: The last three letters of a variable are variable[-3:], and its length is len(word).
