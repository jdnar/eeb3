3. Lists

On this page
  • 3.1 Creating a list
  • 3.2 Inserting elements
  • 3.3 Deleting elements
  • 3.4 Selecting and modifying
  • 3.5 The for and in keywords

Lists are sequences. A list is an object that can contain other objects, whatever their type: lists of integers [1, 2, 50, 2000], of floats, of strings, or a mix of all of them.

3.1 Creating a list

There are two ways to create an empty list: the list() function, or the list delimiters []. You can also create a list that already contains objects.

my_list = list()               # an empty list
my_list = []                   # an empty list
my_list = [1, 2, 3, 4, 5]      # a list with 5 integers
my_list = [3.5, 1, "hello", []]   # a float, an integer, a string and an empty list

3.2 Inserting elements

There are three ways to insert elements in a list.

append

append adds an element at the end of the list.

my_list = [1, 2, 3]
my_list.append(56)
print(my_list)    # [1, 2, 3, 56]

insert

insert adds an element where you want. You give the position first and the element second.

my_list = ['a', 'b', 'd', 'e']
my_list.insert(2, 'c')
print(my_list)    # ['a', 'b', 'c', 'd', 'e']

extend

extend concatenates two (or more) lists into one. Apply it to the list you want to extend and give the other list as parameter. The + operator gives the same result.

my_list1 = [3, 4, 5]
my_list2 = [8, 9, 10]
my_list1.extend(my_list2)
print(my_list1)   # [3, 4, 5, 8, 9, 10]

# The same result with +
my_list1 = [3, 4, 5]
my_list1 = my_list1 + my_list2

3.3 Deleting elements

There are two ways to remove an element.

del

del needs the index of the element to delete.

my_list = [-5, -2, 1, 4, 7, 10]
del my_list[0]
print(my_list)    # [-2, 1, 4, 7, 10]
del my_list[2]
print(my_list)    # [-2, 1, 7, 10]

remove

remove needs the element itself to delete.

my_list = [31, 32, 33, 34, 35]
my_list.remove(32)
print(my_list)    # [31, 33, 34, 35]

3.4 Selecting and modifying

You access the elements of a list exactly like the characters of a string: the index goes between []. The big difference is that a list element can be changed, while a character in a string cannot. To select part of a list, use the same slicing as for strings.

>>> my_list = ['c', 'f', 'm']
>>> my_list[0]
'c'
>>> my_list[2]
'm'
>>> my_list[1] = 'Z'
>>> my_list
['c', 'Z', 'm']
>>> my_list = ["a", 3, "coucou", 7, 10]
>>> my_list[1:3]
[3, 'coucou']
>>> my_list[2:4]
['coucou', 7]
>>> my_list[:3]
['a', 3, 'coucou']
>>> my_list[2:]
['coucou', 7, 10]

Summary

  • You access an element directly with my_list[index] and you can modify it.
  • You select part of a list with my_list[start_index:end_index]; the end_index is not included; omitted start_index means 0; omitted end_index means the end of the list.

3.5 The for and in keywords

To go through every element of a list, the easiest way is a for loop with the in keyword. The control variable (elem below) takes the value of each element in turn.

people = ["Gertrude", "Marc", "Pierre", "Gaetan", "Jacques", "Sancho"]
for elem in people:
    print(elem)
Output
Gertrude
Marc
Pierre
Gaetan
Jacques
Sancho

in is also useful to check whether an element is in a list. Here we add Thomas only if he is not yet there:

people = ["Gertrude", "Marc", "Pierre", "Gaetan", "Jacques", "Sancho"]
if "Thomas" in people:
    print("This name is already in the list.")
else:
    print("This name is not yet in the list, let's add it.")
    people.append("Thomas")
