Your functions now make decisions. Many of them return a boolean (True or False) or a message. You review comparison operators, and, or, not, and if / elif / else.

Exercise 15 — Even or odd?

S4 review: modulus % · booleans

Define a function is_even(n) that returns True if n is even and False otherwise.

Examples (type the calls in the Thonny shell after running your file):

>>> is_even(8)
True
>>> is_even(7)
False
>>> is_even(0)
True
Tip: A comparison already is a boolean: you can return n % 2 == 0 directly, without an if.

Exercise 16 — Is it an adult?

S4 review: comparison operators

Define a function is_adult(age) that returns True if the age is 18 or more.

Examples (type the calls in the Thonny shell after running your file):

>>> is_adult(18)
True
>>> is_adult(17)
False
>>> is_adult(40)
True

Exercise 17 — The larger number

S4 review: if / else · return

Define a function maximum(a, b) that returns the larger of two numbers. Do not use the built-in max().

Examples (type the calls in the Thonny shell after running your file):

>>> maximum(3, 9)
9
>>> maximum(10, 2)
10
>>> maximum(5, 5)
5
Tip: As soon as return runs, the function ends.

Exercise 18 — Positive, negative or zero

S4 review: if / elif / else · strings

Define a function sign(n) that returns the text "positive", "negative" or "zero".

Examples (type the calls in the Thonny shell after running your file):

>>> sign(5)
'positive'
>>> sign(-2)
'negative'
>>> sign(0)
'zero'

Exercise 19 — School grade

S4 review: if / elif / else

Define a function grade(score) that returns "Excellent" if the score is 16 or more, "Pass" if it is 10 or more, and "Fail" otherwise.

Examples (type the calls in the Thonny shell after running your file):

>>> grade(18)
'Excellent'
>>> grade(12)
'Pass'
>>> grade(7)
'Fail'
Tip: Conditions are checked in order, so you do not need to write score >= 10 and score < 16.

Exercise 20 — Is it in the range?

S4 review: and · comparison operators

Define a function in_range(n, low, high) that returns True if n is between low and high, both included.

Examples (type the calls in the Thonny shell after running your file):

>>> in_range(5, 1, 10)
True
>>> in_range(10, 1, 10)
True
>>> in_range(11, 1, 10)
False

Exercise 21 — Leap year

S4 review: and · or · not · modulus %

Define a function is_leap_year(year) that returns True for a leap year. A year is a leap year if it is divisible by 4 and not by 100, or if it is divisible by 400.

Examples (type the calls in the Thonny shell after running your file):

>>> is_leap_year(2024)
True
>>> is_leap_year(1900)
False
>>> is_leap_year(2000)
True
>>> is_leap_year(2023)
False

Exercise 22 — Can I buy it?

S4 review: booleans · if / else · input() · float()

Define a function can_buy(money, price) that returns True if the money is enough. The main program asks both amounts (floats) and, depending on the result of the function, prints either You can buy it! or how much money is missing.

Examples (type the calls in the Thonny shell after running your file):

>>> can_buy(50, 30)
True
>>> can_buy(10, 30)
False

Example run (the user typed 10, 30):

Output
How much money do you have? 10
How much does it cost? 30
You need 20.0 more.

Exercise 23 — The thermostat

S4 review: if / elif / else · strings

Define a function thermostat(current, ideal) that returns the message "Decrease the temperature." if the current temperature is higher than the ideal one, "Increase the temperature." if it is lower, and "Perfect!" if they are equal.

Examples (type the calls in the Thonny shell after running your file):

>>> thermostat(25, 20)
'Decrease the temperature.'
>>> thermostat(15, 20)
'Increase the temperature.'
>>> thermostat(20, 20)
'Perfect!'

Exercise 24 — Ticket price

S4 review: if / elif / else · comparison operators

A cinema sells tickets at these prices: under 12 years old, 5 euros; from 12 to 17, 8 euros; from 18 to 64, 10 euros; 65 or older, 6 euros. Define a function ticket_price(age) that returns the price.

Examples (type the calls in the Thonny shell after running your file):

>>> ticket_price(8)
5
>>> ticket_price(15)
8
>>> ticket_price(30)
10
>>> ticket_price(70)
6
