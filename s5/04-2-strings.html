2. Strings

On this page
  • 2.1 Methods
  • 2.2 Concatenation
  • 2.3 Length
  • 2.4 Selecting characters

The string is the first object we study. An object comes from a class and is a data structure, like a variable, that can contain other variables and functions.

2.1 Methods

Some functions are defined specifically for one kind of object. A function defined for an object is called a method of that object. The syntax to use it is object.method(). There are many predefined methods for strings:

>>> text = "STOP YELLING !"
>>> newText = text.lower()
>>> newText
'stop yelling !'
>>> newText = text.capitalize()
>>> newText
'Stop yelling !'
>>> newText = text.upper()
>>> newText
'STOP YELLING !'

2.2 Concatenation

The + sign concatenates two strings:

>>> name = "Marc"
>>> message = "Hello"
>>> welcome = message + name
>>> welcome
'HelloMarc'
>>> welcome = message + " " + name
>>> welcome
'Hello Marc'
>>> age = 21
>>> welcome = message + " " + name + " you are " + str(21)
>>> welcome
'Hello Marc you are 21'
Note: You can only concatenate strings with strings. To add a number, convert it first with str().

2.3 Length

The function len() returns the number of characters in a string:

>>> text = "Hello"
>>> len(text)
5

2.4 Selecting characters

A string is made of characters, and you can select each one by its index between []. Indexes start at 0, and negative indexes count from the end. To select part of a string, give the start and end index separated by :.

>>> text = "Hello students"
>>> text[0]      # first character
'H'
>>> text[2]      # third character
'l'
>>> text[-1]     # last character
's'
>>> text = "hello, how are you?"
>>> text[7:10]
'how'
>>> text[11:14]
'are'
>>> text[:5]
'hello'
>>> text[7:]
'how are you?'

Summary

  • A string is an object and has its own functions, called methods: object.method().
  • The + sign concatenates two strings.
  • len() returns how many characters a string has.
  • You can access a character directly with its index: text[position].
  • You can select part of a string with my_text[start_index:end_index]. The end_index is not included; if you omit start_index Python assumes 0; if you omit end_index Python goes to the end.
