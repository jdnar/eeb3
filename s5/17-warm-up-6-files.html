Warm-up 6: Files

On this page
  • Step 6.1 — Write
  • Step 6.2 — Append
  • Step 6.3 — Read
  • Step 6.4 — Count the lines

Each step uses a small file called practice.txt in the same folder as your program. Do not forget to close the file every time.

Tip: Type every example yourself instead of copying it, and run it after each step. Solutions: Appendix B.6.

Step 6.1 — Write

Open practice.txt in write mode, write line one followed by a line break ("\n"), and close the file.

Step 6.2 — Append

Open the same file in append mode, add line two with a line break, and close it. Why would write mode have been a mistake here?

Step 6.3 — Read

Open the file in read mode, read all the content into a variable, close the file and print the content.

Output
line one
line two

Step 6.4 — Count the lines

Using the content you read, split it on "\n" and print how many lines the file has (careful with the empty element at the end).

Output
2
