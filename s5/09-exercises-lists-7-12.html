Exercise 7 — exercise7

Write a program that:

  • creates a first list [2, 8, 5, 4, 6, 7, 8, 5];
  • creates a second list [3.5, 'coucou', 8, 'hello', 6.2];
  • inserts the value 3 in the first list between the values 2 and 8;
  • adds the value 72 at the end of the second list;
  • removes 'coucou' from the second list;
  • combines both lists using the extend method;
  • prints the final list;
  • prints the value at index 5 of the list;
  • prints the 4 first elements of the list;
  • prints the 3 last elements of the list;
  • prints the elements from index 2 to index 5 included.

You should get this output:

Output
[2, 3, 8, 5, 4, 6, 7, 8, 5, 3.5, 8, 'hello', 6.2, 72]
6
[2, 3, 8, 5]
['hello', 6.2, 72]
[8, 5, 4, 6]

Exercise 8 — exercise8

Write a function total(list_number) that receives a list of numbers and returns their sum. For [1, 2, 3] it returns 6. Then write a program that:

  • repeatedly asks numbers to the user and adds them to a list until the user enters stop;
  • calls total with the list;
  • prints the result.
Tip: This is the pattern to repeatedly ask numbers until stop (you will reuse it in the next exercises):
listOfNumbers = []
askAgain = True
while askAgain == True:
    answer = input("Give me a number (or write stop if you are done): ")
    if answer == "stop":
        askAgain = False
    else:
        listOfNumbers.append(int(answer))

Exercise 9 — exercise9

Write a function largestNumber(list_number) that returns the largest number of a list. For [1, 2, 10, 3] it returns 10. Then write a program that asks numbers until stop, calls the function, and prints the result.

Tip: Start with a variable for the largest value found so far, go through the list with a for loop, and replace the variable whenever the current item is bigger.

Exercise 10 — exercise10

Write a function size(list_strings) that receives a list of strings and returns how many of them have 5 or more letters. For ['abcdef', 'xyz', 'aba', '1221221221'] it returns 2. Then write a program that asks words until stop, calls the function and prints the result.

Tip: Use len() to check the length of a string.

Exercise 11 — exercise11

Write a function checkZero(list_number) that returns True if there is a zero in the list and False otherwise. For [1, 2, 3] it returns False; for [3, 6, 9, 0, 3] it returns True. Then write a program that asks numbers until stop, calls the function and prints the result.

Exercise 12 — exercise12

Write a function occurrences(list_letters, letter) that receives a list of letters and one letter, and returns two things: how many times the letter appears and a list of the indexes where it appears. For ["a", "e", "b", "a"] and "a" it returns 2 and [0, 3]. Then write a program that:

  • repeatedly asks letters and adds them to a list until the user enters stop;
  • asks the user to pick one letter;
  • calls occurrences with the list and the letter;
  • prints the following:
Output
The letter appears 2 times.
It appears at the following index: [0, 3].
Tip: To return several values write return (variable1, variable2). When you call the function, keep the result in a variable such as result, then read result[0] and result[1] (see section 1.2).
