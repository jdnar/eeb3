Your functions now talk to the user with input(). You review the while loop with a stop condition, conversions with int(), and the "read a sequence of data" pattern.

Exercise 35 — Ask an integer

S4 review: input() · int() · return

Define a function ask_integer(question) that shows the question, reads the answer, converts it to an integer and returns it. The main program uses it twice to ask two numbers and prints their sum.

Example run (the user typed 3, 4):

Output
First number: 3
Second number: 4
7

Exercise 36 — Ask until positive

S4 review: while · input()

Define a function ask_positive() that keeps asking for a number until the user gives one greater than 0, then returns it. If the number is not positive, print That is not positive. Try again.

Example run (the user typed -5, 0, 8):

Output
Give me a positive number: -5
That is not positive. Try again.
Give me a positive number: 0
That is not positive. Try again.
Give me a positive number: 8
Thanks! You gave me 8
Tip: Ask once before the loop, and ask again at the end of the loop body (the "change" part).

Exercise 37 — Sum until stop

S4 review: while · accumulator · input()

Define a function sum_until_stop() that asks for numbers until the user writes stop, and returns the total. Remember that input() returns a string: convert it only when it is not stop.

Example run (the user typed 4, 6, 10, stop):

Output
Give me a number or write stop: 4
Give me a number or write stop: 6
Give me a number or write stop: 10
Give me a number or write stop: stop
Total: 20

Exercise 38 — Average until stop

S4 review: while · counter and accumulator · if / else

Define a function average_until_stop() that asks for numbers until the user writes stop and returns their average. If the user writes stop immediately, return 0 (you cannot divide by zero).

Example run (the user typed 4, 6, 11, stop):

Output
Give me a number or write stop: 4
Give me a number or write stop: 6
Give me a number or write stop: 11
Give me a number or write stop: stop
Average: 7.0

Exercise 39 — Password with attempts

S4 review: while · counter · comparison

Define a function ask_password(correct) that keeps asking for the password until it matches correct, and returns the number of attempts it took. The main program prints how many attempts were needed.

Example run (the user typed abc, 123, python):

Output
Password: abc
Wrong password
Password: 123
Wrong password
Password: python
Welcome! It took you 3 attempt(s).

Exercise 40 — Yes or no

S4 review: while · and · booleans

Define a function yes_or_no(question) that asks the question followed by (yes/no) and keeps asking until the user answers exactly yes or no. It returns True for yes and False for no.

Example run (the user typed maybe, yes):

Output
Do you like Python? (yes/no) maybe
Please answer yes or no.
Do you like Python? (yes/no) yes
Great!
Tip: Careful: to refuse both words you need and, not or.
