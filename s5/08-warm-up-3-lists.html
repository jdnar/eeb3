Warm-up 3: Lists

On this page
  • Step 3.1 — Create a list
  • Step 3.2 — Insert elements
  • Step 3.3 — Delete elements
  • Step 3.4 — Select and modify
  • Step 3.5 — for and in

Follow the theory of Chapter 3 step by step; keep working on the same list when it says so.

Tip: Type every example yourself instead of copying it, and run it after each step. Solutions: Appendix B.3.

Step 3.1 — Create a list

Create an empty list called numbers using [], then create a list fruits containing three fruit names. Print both.

Step 3.2 — Insert elements

Start with numbers = []. Use append to add 10 and 20, then insert to put 15 between them, and print the list. Finally use extend to add [30, 40] and print again.

Output
[10, 15, 20]
[10, 15, 20, 30, 40]

Step 3.3 — Delete elements

Continue with the list [10, 15, 20, 30, 40]. Delete the first element with del, then remove the value 30 with remove. Print the list after each step.

Output
[15, 20, 30, 40]
[15, 20, 40]

Step 3.4 — Select and modify

Continue with [15, 20, 40]. Change the first element to 99, then print the whole list and the slice from index 1 to 3 (end not included).

Output
[99, 20, 40] [20, 40]

Step 3.5 — for and in

With the list [99, 20, 40], use a for loop to print each element multiplied by 2. Then use in to print True or False depending on whether 20 is in the list.
