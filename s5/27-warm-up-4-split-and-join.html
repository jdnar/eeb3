Warm-up 4: Split & Join

Two very short steps for Chapter 4.

Tip: Type every example yourself instead of copying it, and run it after each step. Solutions: Appendix B.4.

Step 4.1 — Split

Split the string "I love Python" on spaces into a list called words. Print the list and its length.

Output
['I', 'love', 'Python']
3

Step 4.2 — Join

Join the list words back into a string using - as separator, and print it.

Output
I-love-Python
