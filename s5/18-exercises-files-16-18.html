Exercise 16 — exercise16

Write a program that opens the file words.txt, reads its content, prints it, and closes it.

my_file = open(r"pathToYourFile\file.txt", "r")
content = my_file.read()
print(content)
my_file.close()

Exercise 17 — exercise17

Write a program that opens a text file located on your computer, writes some content in it, and closes it.

Tip: You can open in "a" (append) or "w" (write) mode. Write mode erases the previous content; append mode adds the new content at the end.

Exercise 18 — exercise18

Write a function getWord(file) that receives the path to a file and returns one word randomly selected from that file. Then write a program that sets the file variable to the path of words.txt, calls getWord(file) and prints the selected word.

Tip: When you read a file you get one big string. Split it on "\n" (the line break) to get a list with one element per line: content = content.split("\n"). To pick a random element, import random and use my_list[random.randint(0, len(my_list) - 1)].
