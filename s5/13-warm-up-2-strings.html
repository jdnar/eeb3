Warm-up 2: Strings

On this page

  • Step 2.2 — Concatenation
  • Step 2.3 — Length

One tiny task for each idea of Chapter 2.

Tip: Type every example yourself instead of copying it, and run it after each step.

Step 2.1 — Methods

Create the variable t = "hello world" and print it in upper case, in lower case and capitalized (three print calls).

Step 2.2 — Concatenation

With the variables name = "Marc" and age = 21, build and print the sentence Hello Marc you are 21. Remember str().

Output
Hello Marc you are 21

Step 2.3 — Length

Print how many characters the word "Python" has.

Step 2.4 — Selecting characters: predict the output

With w = "Python", write down what each line prints before running it. Then check.

print(w[0])
print(w[-1])
print(w[:3])
print(w[2:])
print(w[1:4])
