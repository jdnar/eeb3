Warm-up 1: Functions

On this page
  • Step 1.1 — Create and call a function
  • Step 1.2 — Give the function an input
  • Step 1.3 — Two parameters and a return value
  • Step 1.4 — Use the returned value
  • Step 1.5 — Local variables: predict the error
  • Step 1.6 — Return two values

These small steps follow the theory of Chapter 1 one idea at a time. Do them before the main exercises.

Tip: Type every example yourself instead of copying it, and run it after each step. Solutions: Appendix B.1.

Step 1.1 — Create and call a function

Define a function say_hello() that prints Hello!. Then call it three times.

Output
Hello!
Hello!
Hello!

Step 1.2 — Give the function an input

Define a function greet(name) that prints Hello, followed by the name and !. Call it with two different names, for example "Ana" and "Luis".

Output
Hello, Ana!
Hello, Luis!

Step 1.3 — Two parameters and a return value

Define a function rectangle_area(width, height) that returns the area of a rectangle. Print the result of rectangle_area(3, 5).

Output
15

Step 1.4 — Use the returned value

Define a function double(n) that returns n * 2. Save double(4) in a variable x, then print x + 1.

Output
9

Step 1.5 — Local variables: predict the error

What happens when you run this code? Explain why, then fix it so it prints 5.

def make_total(a, b):
    total = a + b
    return total

make_total(2, 3)
print(total)

Step 1.6 — Return two values

Define a function min_max(a, b) that returns the smaller number first and the larger number second. Call it with 9 and 4, save the result in r and print r[0] and r[1].

Output
4 9
