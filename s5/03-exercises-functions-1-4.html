Exercises: Functions (1–4)

Save each exercise in your Python folder under the name indicated.

Exercise 1 — exercise1

Define a function called multiplication that takes two numbers as parameters and returns their product. Then write a program that:

  • asks two numbers to the user;
  • calls multiplication with those numbers and saves the returned value in a variable result;
  • prints result.
Tip: Ask a number with number = int(input("question")). Call the function with multiplication(number1, number2) and keep its result with result = multiplication(number1, number2).

Exercise 2 — exercise2

Define a function draw that draws a structure based on its parameter. If the parameter is 4 the output is:

Output
*
**
***
****

With parameter 2 it prints:

Output
*
**

Then write a program that asks the user how big the drawing should be and calls draw with that number.

Tip: Create a for loop with range inside draw; at each iteration print the right number of *.

Exercise 3 — exercise3

Define a function two_equals(a, b, c) that receives three numbers and returns True if at least two of them have the same value, False otherwise. Then write a program that reads three integers x, y, z and shows the result of two_equals(x, y, z).

Exercise 4 — exercise4

Define a function divisible(a, b) that returns True if a is divisible by b, False otherwise. Then write a program that reads two integers x, y and shows the result of divisible(x, y).

Tip: Use the modulus operator %, which gives the remainder of a division. If there is no remainder, the number is divisible: if a % b == 0:.
