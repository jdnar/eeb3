1. Functions

A function is a block of organized, reusable code that performs a single, related action. Functions make your application more modular and let you reuse code instead of copying it.

Think of a function as a tool that solves one problem. Other parts of the program can use this tool without worrying about how it works inside: they only need to know its name, the values it requires, and how it returns its result(s).

1.1 Creating a function

To define a function you write the keyword def, the function name, the parameters in parentheses separated by commas, and a colon. The instructions of the function follow, indented. An optional return sends a value back.

def name(parameters_separated_by_comma):
    instructions
    return something   # optional

Example:

def sum_of_numbers(a, b):
    result = a + b
    return result

We define a function called sum_of_numbers that receives two parameters, a and b. It calculates their sum and returns the result.

Note: All the instructions that belong to a function are indented.

1.2 Using (calling) a function

To use a function you write its name followed by the values (called arguments) in parentheses:

name(parameters_separated_by_comma)

When you call a function, it behaves like a black box: it takes some input, processes it, and gives an output.

Input: parameters

Variables are most of the time local: a function is not aware of variables defined outside its body. To give information to a function, you use parameters.

def sum_of_numbers(a, b):
    result = a + b
    return result

sum_of_numbers(4, 8)

Here we call the function with 4 and 8. Python automatically assigns the value 4 to a and 8 to b.

Output: what a function can do

A function has three possibilities when it comes to output. It can:

  • print something on the screen;
  • change data in memory (for example, change the content of a file);
  • return a value.

Variables defined inside a function exist only inside that function. If you want to give the content of a variable back at the end, use return. When you use return, the call to the function is replaced by the returned value.

def sum_of_numbers(a, b):
    result = a + b
    return result

x = sum_of_numbers(4, 8)

The call sum_of_numbers(4, 8) is replaced by the value of result, so x is 12.

Returning several values

A function can return more than one value by separating them with commas (Python packs them in a tuple). You save the returned value in a variable and read each part by its index:

def example():
    a = 8
    b = "coucou"
    return (a, b)

x = example()
print(x[0])   # prints 8
print(x[1])   # prints "coucou"
