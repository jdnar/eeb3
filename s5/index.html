How to Use This Course

On this page
  • Course map
  • What you should already know
  • Tools and habits

This course covers the second block of the Python path: you will learn to organize your code with functions, and to work with the main data structures of the language — strings, lists and dictionaries — and with files. It ends with a complete game, the Hangman. Each chapter has the same rhythm: short theory, runnable examples, a warm-up with very easy steps (one per idea of the theory), and then the main exercises. Solutions are collected in the appendices — try each step yourself first.

What you should already know

  • Variables and the basic data types (integers, floats, strings, booleans).
  • How to read input with input() and show output with print().
  • Conditionals (if / elif / else), while and for loops with range().
  • The random module (it is used again in this course).

Tools and habits

  • Write and run your code in Thonny, a beginner-friendly Python editor (any other editor works too).
  • Create a folder called Python and save every exercise in it with the name given in the exercise (exercise1, exercise2, …).
  • The lines >>> %Run exercise.py in the sample outputs are what Thonny prints when you run a script; your program should produce the lines that follow.
Important: Two exercises (16 and 18) and the Hangman project use a text file called words.txt. In the original course it is provided by the teacher. If you do not have it, create it yourself: a plain text file with one word per line (words of up to eight letters), saved in the same folder as your programs.
