Warm-up 5: Dictionaries

On this page
  • Step 5.1 — Create and read
  • Step 5.2 — Modify, add and remove
  • Step 5.3 — Check a key
  • Step 5.4 — Loop over a dictionary

Practice each dictionary operation of Chapter 5 on a very small dictionary.

Tip: Type every example yourself instead of copying it, and run it after each step. Solutions: Appendix B.5.

Step 5.1 — Create and read

Create a dictionary pet with the keys "name" (value "Rex") and "age" (value 3). Print the value of "name".

Step 5.2 — Modify, add and remove

Change the age to 4, add a new key "color" with the value "brown", then delete the key "age". Print the dictionary.

Step 5.3 — Check a key

Print True or False depending on whether the key "color" is in pet, using in.

Step 5.4 — Loop over a dictionary

Use a for loop to print each key followed by its value.
