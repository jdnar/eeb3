Exercise 25 — Print the numbers

S4 review: for · range()

Define a function print_numbers(n) that prints the integers from 1 to n (included), one per line. Call it with 5.

Expected output:

Output
1
2
3
4
5
Tip: The end value of range is not included.

Exercise 26 — Countdown

S4 review: while · initialisation / condition / change

Define a function countdown(n) that uses a while loop to print n, n - 1, …, 1 and finally Liftoff!. Call it with 5.

Expected output:

Output
5
4
3
2
1
Liftoff!

Exercise 27 — Sum from 1 to n

S4 review: for · accumulator

Define a function sum_to(n) that returns 1 + 2 + … + n.

Examples (type the calls in the Thonny shell after running your file):

>>> sum_to(10)
55
>>> sum_to(100)
5050
>>> sum_to(1)
1
Tip: Create total = 0 before the loop and return total after it (not inside it).

Exercise 29 — Factorial

S4 review: for · accumulator

Define a function factorial(n) that returns n!, the product of all the integers from 1 to n. By definition 0! = 1.

Examples (type the calls in the Thonny shell after running your file):

>>> factorial(5)
120
>>> factorial(1)
1
>>> factorial(0)
1
>>> factorial(10)
3628800
Tip: Start the accumulator at 1, not at 0: multiplying by 0 would always give 0.

Exercise 31 — Count the divisors

S4 review: for · modulus % · counter

Define a function count_divisors(n) that returns how many integers between 1 and n (both included) divide n exactly.

Examples (type the calls in the Thonny shell after running your file):

>>> count_divisors(12)
6
>>> count_divisors(7)
2
>>> count_divisors(1)
1

Exercise 32 — Prime numbers

S4 review: functions calling functions · booleans

A prime number has exactly two divisors: 1 and itself. Define a function is_prime(n) that returns True or False. Reuse your count_divisors function from the previous exercise!

Examples (type the calls in the Thonny shell after running your file):

>>> is_prime(7)
True
>>> is_prime(12)
False
>>> is_prime(2)
True
>>> is_prime(1)
False

Exercise 33 — Sum of the even numbers

S4 review: for · range() with a step · if

Define a function sum_of_evens(n) that returns the sum of the even numbers between 1 and n. Write it first with an if inside the loop, then try again with range(2, n + 1, 2).

Examples (type the calls in the Thonny shell after running your file):

>>> sum_of_evens(10)
30
>>> sum_of_evens(7)
12
>>> sum_of_evens(1)
0

Exercise 34 — Power without **

S4 review: for · accumulator

Define a function power(base, exponent) that returns base raised to exponent using a loop (and not the ** operator). The exponent is an integer greater than or equal to 0.

Examples (type the calls in the Thonny shell after running your file):

>>> power(2, 10)
1024
>>> power(5, 0)
1
>>> power(3, 3)
27
