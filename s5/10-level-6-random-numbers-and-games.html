You use the random module inside functions. Because the results are random, run your program several times to check it. You also write the building blocks of small games.

Exercise 41 — Roll a die

S4 review: import random · randint

Define a function roll_die() that returns a random integer between 1 and 6 (both included). The main program prints You rolled followed by the result.

The output is random, so it changes every time you run the program.

Tip: Put import random at the very top of your file.

Exercise 42 — Flip a coin

S4 review: random.choice

Define a function flip_coin() that returns "heads" or "tails" at random.

The output is random, so it changes every time you run the program.

Exercise 43 — Roll several dice

S4 review: for · accumulator · randint · functions calling functions

Define a function roll_dice(n) that rolls n dice and returns the sum of the results. Reuse roll_die().

The output is random, so it changes every time you run the program.

Exercise 44 — Too low, too high

S4 review: if / elif / else · strings

Define a function check_guess(secret, guess) that returns "too low" if the guess is smaller than the secret number, "too high" if it is larger, and "correct" if they are equal. (You will use it in the first mini-project.)

Examples (type the calls in the Thonny shell after running your file):

>>> check_guess(5, 3)
'too low'
>>> check_guess(5, 8)
'too high'
>>> check_guess(5, 5)
'correct'

Exercise 45 — Who wins?

S4 review: if / elif / else · and · or

In Rock-Paper-Scissors, rock beats scissors, scissors beats paper and paper beats rock. Define a function winner(player, computer) that receives two moves ("rock", "paper" or "scissors") and returns "player", "computer" or "draw".

Examples (type the calls in the Thonny shell after running your file):

>>> winner("rock", "scissors")
'player'
>>> winner("paper", "rock")
'player'
>>> winner("rock", "paper")
'computer'
>>> winner("paper", "paper")
'draw'

Exercise 46 — The computer’s move

S4 review: random.choice · return

Define a function random_move() that returns "rock", "paper" or "scissors" at random.

The output is random, so it changes every time you run the program.
