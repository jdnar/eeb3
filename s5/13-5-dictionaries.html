5. Dictionaries

A dictionary stores and retrieves data using key-value pairs. It works like a real dictionary: you look up a word (the key) to find its definition (the value). The most important concepts:

ConceptMeaning
Key-value pairsA dictionary is a collection of pairs; each key is a unique identifier for a piece of data and the value is the data itself.
UnorderedUnlike lists, the elements of a dictionary do not have a specific order or position.
MutableA dictionary can be modified after creation: add, change or remove pairs as needed.
Unique keysYou cannot have two identical keys with different values.

A complete example:

# Creating a dictionary
student = {
    "name": "Alice",
    "age": 25,
    "grade": "A"
}

# Accessing values using keys
print(student["name"])    # Alice

# Modifying values
student["age"] = 26

# Adding a new key-value pair
student["city"] = "New York"

# Removing a key-value pair
del student["grade"]

# Checking if a key exists
if "city" in student:
    print("City:", student["city"])

Dictionaries are versatile and useful for a wide range of tasks.

Looping over a dictionary

A for loop over a dictionary goes through its keys:

for key in dico:
    print(key, ":", dico[key])
