Exercises: Dictionaries (14–15)

Exercise 14 — exercise14

Use a dictionary to store the grades of different students. Here are the grades:

NameGrade
"Alice"92
"Bob"85
"Charlie"78
"David"95
"Eve"88
  • Create a dictionary initialised with the names and grades above.
  • Print the grade of Alice and the grade of Charlie.
  • Add a new student Franck with grade 89.
  • Change the grade of Bob to 87.
  • Eve left the school: remove her from the dictionary.
  • Using for and in, display all the students and their grades.
Tip: Create: dico = {"a": 1, "b": 2}. Read: dico["a"]. Add: dico["c"] = 3. Modify: dico["a"] = "hello". Remove: del dico["a"].

Exercise 15 — exercise15

Write a program that takes a text as input (words separated by spaces), counts the frequency of each word, stores the frequencies in a dictionary and prints the result. Example:

Output
give me some words seperated by space: this is a simple example this is a test
'this': 2
'is': 2
'a': 2
'simple': 1
'example': 1
'test': 1
Tip: Split the text with words = text.split(" "). Start with an empty dictionary and loop over words: if the word is already a key, increase its value by one; if not, add it with the value 1.
