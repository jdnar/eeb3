Level 7: Mini-projects with Several Functions

Time to combine everything. Each mini-project is split into small functions that cooperate. First design the functions on paper (name, parameters, what they return), then code them one by one and test each one before moving on.

Mini-project 1: Guess the number (with functions)

S4 review: functions · while · random · conditionals

Rewrite the game of the S4 projects using functions. Write: ask_guess() that asks an integer between 1 and 10 and returns it; check_guess(secret, guess) (from Level 6); and play() that picks a secret number, gives the player three attempts, prints too low or too high after each wrong guess, congratulates the player if they find the number, and tells the secret number if they run out of attempts.

The output is random, so it changes every time you run the program.

Tip: play() can call ask_guess() and check_guess() from the same line: check_guess(secret, ask_guess()).

Mini-project 2: A calculator

S4 review: functions · if / elif / else · while · input()

Write a function calculate(a, operator, b) that receives two numbers and one of the texts "+", "-", "*" or "/", and returns the result. If the operator is unknown, or if the program would divide by zero, it returns None (the "empty" value). The main program asks two numbers and an operator, prints the result or Invalid operation, and asks Another one? (yes/no) until the user answers something other than yes.

Examples (type the calls in the Thonny shell after running your file):

>>> calculate(8, "+", 2)
10
>>> calculate(9, "/", 0)
None
>>> calculate(6, "*", 7)
42
>>> calculate(1, "x", 2)
None

Example run (the user typed 8, +, 2, yes, 9, /, 0, yes, 7, *, 6, no):

Output
First number: 8
Operator (+ - * /): +
Second number: 2
Result: 10.0
Another one? (yes/no) yes
First number: 9
Operator (+ - * /): /
Second number: 0
Invalid operation
Another one? (yes/no) yes
First number: 7
Operator (+ - * /): *
Second number: 6
Result: 42.0
Another one? (yes/no) no

Mini-project 3: Times-table quiz

S4 review: functions · for · random · counter

Write ask_question(): it picks two random integers between 1 and 10, asks a x b = and returns True if the answer is correct and False otherwise (printing the right answer when it is wrong). Then write quiz(n): it asks n questions and returns the number of correct answers. The main program asks the user how many questions they want and prints Score: x / n.

The output is random, so it changes every time you run the program.

Tip: An if can test a function that returns a boolean directly: if ask_question():.

Mini-project 4: Rock, Paper, Scissors

S4 review: functions · random · while · conditionals

Rebuild your Rock-Paper-Scissors game from the S4 projects with functions. Reuse winner and random_move from Level 6 and add play_round(): it asks the player’s move, gets the computer’s move, prints both and who won, and returns "player", "computer" or "draw". The main program keeps the score and asks Play again? (yes/no) after each round.

The output is random, so it changes every time you run the program.

Mini-project 5: Temperature table

S4 review: functions calling functions · for · range() with a step · print()

Reuse celsius_to_fahrenheit from Level 2. Define print_temperature_table(start, stop, step) that prints one line per Celsius value from start to stop (both included), going up by step, in the format shown. Call it with 0, 100 and 20.

Expected output:

Output
0 C = 32.0 F
20 C = 68.0 F
40 C = 104.0 F
60 C = 140.0 F
80 C = 176.0 F
100 C = 212.0 F
Tip: The end value of range is not included, so use stop + 1.
