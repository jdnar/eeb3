Now your functions return a result with return, and the main program decides what to do with it. You review operators (+ - * / ** % //), int/float and the difference between printing and returning.

Exercise 6 — Add two numbers

S4 review: operators · return · input()

Define a function add(a, b) that returns the sum of its two parameters. The main program asks two integers and prints The sum is followed by the result.

Examples (type the calls in the Thonny shell after running your file):

>>> add(2, 3)
5
>>> add(-4, 10)
6
>>> add(0.5, 0.25)
0.75

Example run (the user typed 7, 8):

Output
First number: 7
Second number: 8
The sum is 15
Tip: return sends the value back: the call add(7, 8) is replaced by 15.

Exercise 8 — Perimeter and area

S4 review: variables · operators · float()

Define two functions, rectangle_perimeter(length, width) and rectangle_area(length, width), that return the perimeter and the area of a rectangle. The main program asks the length and the width (floats) and prints both results on one line.

Examples (type the calls in the Thonny shell after running your file):

>>> rectangle_perimeter(5, 3)
16
>>> rectangle_area(5, 3)
15

Example run (the user typed 8, 9):

Output
Give me a length: 8
Give me a width: 9
Area: 72.0 Perimeter: 34.0

Exercise 9 — The average

S4 review: operators · order of operations

Define a function average(a, b, c) that returns the average of three numbers.

Examples (type the calls in the Thonny shell after running your file):

>>> average(10, 20, 30)
20.0
>>> average(5, 5, 5)
5.0
>>> average(0, 0, 9)
3.0
Tip: Parentheses matter: a + b + c / 3 is not the average.

Exercise 10 — Celsius to Fahrenheit

S4 review: operators · float

Define a function celsius_to_fahrenheit(celsius) that returns the temperature in Fahrenheit using the formula F = C × 9 / 5 + 32.

Examples (type the calls in the Thonny shell after running your file):

>>> celsius_to_fahrenheit(0)
32.0
>>> celsius_to_fahrenheit(100)
212.0
>>> celsius_to_fahrenheit(-40)
-40.0

Exercise 11 — Area of a circle

S4 review: variables · operators

Define a function circle_area(radius) that returns the area of a circle, using pi = 3.14159 stored in a variable inside the function (area = pi × radius²).

Examples (type the calls in the Thonny shell after running your file):

>>> circle_area(1)
3.14159
>>> circle_area(2)
12.56636
>>> circle_area(0)
0.0
Tip: Variables created inside a function are local: they exist only while the function runs.

Exercise 12 — Quotient and remainder

S4 review: operators // and % · returning two values

Define a function quotient_and_remainder(a, b) that returns two values: the truncated quotient and the remainder of a divided by b. The main program asks two integers and prints the result in the format shown.

Examples (type the calls in the Thonny shell after running your file):

>>> quotient_and_remainder(9, 4)
(2, 1)
>>> quotient_and_remainder(20, 5)
(4, 0)

Example run (the user typed 9, 4):

Output
Give me a first number: 9
Give me a second number: 4
9 : 4 = quotient 2 and remainder 1
Tip: Return two values with return (value1, value2), and read them with result[0] and result[1].

Exercise 14 — Hours and minutes

S4 review: operators // and % · returning two values

Define a function to_hours_minutes(total_minutes) that converts a number of minutes into hours and minutes and returns both values. The main program asks the number of minutes and prints it like 135 minutes = 2 h 15 min.

Examples (type the calls in the Thonny shell after running your file):

>>> to_hours_minutes(135)
(2, 15)
>>> to_hours_minutes(60)
(1, 0)
>>> to_hours_minutes(45)
(0, 45)

Example run (the user typed 135):

Output
How many minutes? 135
135 minutes = 2 h 15 min
