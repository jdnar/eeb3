Level 1: Functions that Print

On this page
  • Exercise 1 — The welcome function
  • Exercise 2 — A separator line
  • Exercise 3 — Greet the user

In this level your functions only show things on the screen. You practise def, calling a function, parameters and print(), while reviewing strings, variables and simple operators.

Exercise 1 — The welcome function

S4 review: print() · calling a function

Define a function welcome() that prints two lines: Welcome to my program! and Let's start. Then, in your main program, call it twice.

Expected output:

Output
Welcome to my program!
Let's start.
Welcome to my program!
Let's start.
Tip: A function without parameters has empty parentheses. The instructions inside the function are indented.

Exercise 2 — A separator line

S4 review: string multiplication · print()

Define a function separator() that prints a line of 30 = characters. Use it to frame a title: call separator(), print Python Practice, call separator() again.

Expected output:

Output
==============================
Python Practice
==============================
Tip: Remember that multiplying a string by a number repeats it: "ab" * 3 gives "ababab".

Exercise 3 — Greet the user

S4 review: input() · parameters · concatenation

Define a function greet(name) that prints Hello, followed by the name and !, and then the line Nice to meet you. In the main program, ask the user their name with input and call greet.

Example run (the user typed Marc):

Output
What is your name? Marc
Hello, Marc!
Nice to meet you.

Exercise 4 — Introduce a person

S4 review: input() · int() · operators

Define a function introduce(name, age) that prints, on one line, the name, the age, and how old the person will be next year. The main program asks the name and the age (an integer) and calls the function.

Example run (the user typed Ana, 14):

Output
Name: Ana
Age: 14
Ana is 14 years old and will be 15 next year.
Tip: Items separated by commas in print are shown separated by a space.

Exercise 5 — Repeat a text

S4 review: string multiplication · parameters

Define a function repeat(text, times) that prints text repeated times times on a single line. Test it with repeat("ha", 3) and repeat("*", 10).

Expected output:

Output
hahaha
**********
