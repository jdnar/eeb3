How to Use This Practice Sheet

On this page

You learned the fundamentals of Python in S4 (variables, input/output, conditionals, loops and random), and you have just met functions. This sheet makes the two meet: every exercise asks you to write one or more functions whose insides use something you already learned in S4. You practise the new skill and review the old one at the same time.

How the exercises work

  1. Read the exercise and the S4 review line, which tells you which concepts you are practising.
  2. Write the function(s) in a file saved in your Python folder (for example exercise1.py).
  3. Below the function(s), write a short main program that calls them. Functions must be defined before the line that calls them.
  4. Compare your results with the Examples and Example runs. For functions that return a value, you can test the examples directly in the Thonny shell after running your file.
  5. Only then look at the solution at the end. There are many correct solutions: yours only needs to give the expected results.

Quick reminder: functions

def function_name(parameter1, parameter2):
    instructions          # indented
    return result         # optional

value = function_name(argument1, argument2)   # the call is replaced by the result
  • Parameters are the inputs of the function; the values you give when calling it are the arguments.
  • print() only shows something on the screen. return sends a value back to the program that called the function. They are not the same thing!
  • As soon as return runs, the function ends.
  • Variables created inside a function are local: they do not exist outside of it.
  • To return several values, separate them with commas: return (a, b). Read them with result[0] and result[1].
  • A function can call other functions.

Rules of the game

  • Use only what you know from S4 plus functions: print, input, int, float, str, range, operators, conditionals, loops and the random module.
  • Do not use built-in shortcuts that hide the exercise (for example max(), sum() or ** when the exercise says to use a loop).
  • Give your functions and variables clear names, exactly as written in each exercise.
Tip: Not sure where to start? Write the first line of the function (def ...:) from the exercise text, add return 0 or pass-like placeholders, and improve it step by step, testing after every change.
