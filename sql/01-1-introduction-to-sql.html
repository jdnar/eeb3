1. Introduction to SQL

On this page
  • 1.1 Relational databases
  • 1.2 Statements
  • 1.3 Your first query

SQL, the Structured Query Language, is a programming language designed to manage data stored in relational databases. It works through simple, declarative statements: you describe what you want, and the database figures out how to do it. This keeps data accurate and secure and helps maintain the integrity of databases of any size.

SQL is used across web frameworks and database applications, and the concepts you learn here apply to nearly every data storage system. The statements in this course use the SQLite relational database management system (RDBMS).

Note: IBM originally created SQL in the 1970s under the name SEQUEL (Structured English QUEry Language) to query databases.

1.1 Relational databases

A relational database organizes information into one or more tables.

  • A table is a collection of data organized into rows and columns. Tables are sometimes called relations.
  • A column is a set of data values of one particular type.
  • A row is a single record in a table.

Every value in a relational database has a data type. The most common ones are:

Data typeMeaning
INTEGERA positive or negative whole number
TEXTA text string
DATEA date formatted as 'YYYY-MM-DD'
REALA decimal value

1.2 Statements

A statement is text that the database recognizes as a valid command. Statements always end with a semicolon ;.

CREATE TABLE table_name (
   column_1 data_type,
   column_2 data_type,
   column_3 data_type
);

Let us break the statement down:

  • CREATE TABLE is a clause. Clauses perform specific tasks in SQL. By convention they are written in capital letters. Clauses are also called commands.
  • table_name is the name of the table the command is applied to.
  • (column_1 data_type, ...) is a parameter: a list of columns, data types or values passed to a clause. Here it is the list of column names and their types.
Note: The structure of SQL statements varies. The number of lines does not matter: a statement can be written on one line or split across several lines to make it easier to read.

1.3 Your first query

  1. Open the online editor at https://sqliteonline.com/.
  2. Choose File > Open DB and select the file myFirstDb.db.
  3. Type the following command and click Run:
SELECT * FROM celebs;

Answer these questions about the result:

QuestionAnswer
What are the table, columns and rows?The table is celebs. The columns are id, name and age. The first row has id 1, name Justin Bieber and age 22.
Which parts of the statement are clauses?SELECT and FROM.
Which table is the command applied to?The table celebs.
