Warm-up 5: Multiple Tables

Practice database: Download pets-owners.db or the SQL setup script. If you open the prebuilt database, skip the setup script.

One small join exercise for each idea of Chapter 5, using pets and owners.

Tip: Type every statement yourself and run it after each step. Solutions: Appendix B.5.

Step 5.1 — JOIN

Show each pet's name (heading pet) next to its owner's name (heading owner), ordered by the pet's id.

Expected result:

pet | owner
Rex | Ana
Mia | Luis
Luna | Ana
Max | Sofia
Coco | Luis
Tom | Sofia
Tip: Both tables have a name column, so always write table_name.column_name.

Step 5.2 — Inner join: what disappears?

Count the rows of the join between pets and owners. There are 8 pets: why is the result smaller?

Expected result:

COUNT(*)
6

Step 5.3 — LEFT JOIN

Repeat Step 5.1 but keep all the pets, even those without an owner.

Expected result:

pet | owner
Rex | Ana
Mia | Luis
Bubbles | NULL
Luna | Ana
Max | Sofia
Coco | Luis
Rocky | NULL
Tom | Sofia

Step 5.4 — LEFT JOIN + IS NULL

Use a left join and a WHERE clause to list only the pets that have no owner.

Expected result:

name
Bubbles
Rocky

Step 5.5 — Primary key and foreign key

Answer without running anything: which column is the primary key of owners? Which column of pets is a foreign key, and which primary key does it refer to?

Step 5.6 — CROSS JOIN

Create a small table days with one column day and the values 'Mon' and 'Tue'. Then show every owner paired with every day. How many rows do you expect before running it?

Expected result:

name | day
Ana | Mon
Ana | Tue
Luis | Mon
Luis | Tue
Sofia | Mon
Sofia | Tue
Omar | Mon
Omar | Tue

Step 5.7 — UNION

Stack the names of the owners and the names of the pets in one single column.

Expected result:

name
Ana
Bubbles
Coco
Luis
Luna
Max
Mia
Omar
Rex
Rocky
Sofia
Tom

Step 5.8 — WITH

Using WITH, first count the pets of each owner_id in a temporary table pet_counts. Then join it with owners to show each owner’s name and number of pets, ordered by owner name.

Expected result:

name | pets
Ana | 2
Luis | 2
Sofia | 2
