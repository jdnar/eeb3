2. Manipulation

This chapter covers the six statements used to build and modify a table: CREATE, INSERT, SELECT, ALTER, UPDATE and DELETE, plus constraints that protect your data.

2.1 CREATE

CREATE TABLE creates a new table in the database. The statement below creates a table named celebs:

CREATE TABLE celebs (
   id INTEGER,
   name TEXT,
   age INTEGER
);
  • CREATE TABLE tells SQL you want a new table.
  • celebs is the name of the table.
  • The list in parentheses defines each column (attribute) and its data type: id stores an INTEGER, name stores TEXT, and age stores an INTEGER.

2.2 INSERT

INSERT INTO adds a new row to a table. Use it whenever you want to add new records.

INSERT INTO celebs (id, name, age)
VALUES (1, 'Justin Bieber', 22);
  • INSERT INTO adds the specified row or rows.
  • celebs is the table the row is added to.
  • (id, name, age) lists the columns that will receive data.
  • VALUES introduces the data being inserted, here (1, 'Justin Bieber', 22): the integer 1 goes in id, the text Justin Bieber in name, and 22 in age.

To go further: inserting several rows at once

INSERT INTO MyTable
   ( Column1, Column2, Column3 )
VALUES
   ('John', 123, 'Lloyds Office'),
   ('Jane', 124, 'Lloyds Office'),
   ('Billy', 125, 'London Office'),
   ('Miranda', 126, 'Bristol Office');

2.3 SELECT

SELECT fetches data from a database. The statement below returns all the data in the name column of celebs:

SELECT name FROM celebs;
  • SELECT marks the statement as a query. You use it every time you read data.
  • name is the column to read, and FROM celebs is the table to read it from.
  • A SELECT always returns a new table called the result set.

To read every column, use the wildcard *:

SELECT * FROM celebs;
Important: * is a special wildcard character. It selects every column of a table without naming each one individually.

2.4 ALTER

ALTER TABLE changes an existing table. The statement below adds a new column twitter_handle:

ALTER TABLE celebs
ADD COLUMN twitter_handle TEXT;
  • ALTER TABLE lets you make the specified changes to the table celebs.
  • ADD COLUMN adds a new column; twitter_handle is its name and TEXT its data type.
Important: NULL is a special SQL value that represents missing or unknown data. Rows that existed before the column was added have NULL in twitter_handle.

2.5 UPDATE

UPDATE edits existing records. The statement below gives the record with id 4 the Twitter handle @taylorswift13:

UPDATE celebs
SET twitter_handle = '@taylorswift13'
WHERE id = 4;
  • SET indicates the column to edit and its new value.
  • WHERE indicates which row(s) to update. Here only the row whose id is 4 is changed.
Important: Always include a WHERE clause with UPDATE. Without it, every row of the table is modified.

2.6 DELETE

DELETE FROM removes one or more rows from a table. The statement below deletes all records without a Twitter handle:

DELETE FROM celebs
WHERE twitter_handle IS NULL;
  • DELETE FROM celebs says which table to delete rows from.
  • WHERE selects which rows to delete.
  • IS NULL is a condition that is true when the value is NULL and false otherwise.

2.7 Constraints

Constraints add information about how a column may be used. They are written after the data type of a column and tell the database to reject inserted data that breaks a rule.

CREATE TABLE celebs2 (
   id INTEGER PRIMARY KEY,
   name TEXT UNIQUE,
   date_of_birth TEXT NOT NULL,
   date_of_death TEXT DEFAULT 'Not Applicable'
);
ConstraintEffect
PRIMARY KEYUniquely identifies each row. Inserting a row with a value already present in this column causes a constraint violation and the row is rejected.
UNIQUEEvery row must have a different value. Similar to PRIMARY KEY, except that a table can have many UNIQUE columns.
NOT NULLThe column must have a value. Inserting a row without one is a constraint violation.
DEFAULTTakes an extra argument: the value assumed when an inserted row does not specify one for this column.
