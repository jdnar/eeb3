Warm-up 2: Manipulation

One small task for each statement of Chapter 2, all on a new table called books. Start with an empty database. Each step continues from the previous one.

Tip: Type every statement yourself and run it after each step. Solutions: Appendix B.2.

Step 2.1 — CREATE a table

Create a table books with four columns: id (INTEGER), title (TEXT), author (TEXT) and year (INTEGER).

Step 2.2 — INSERT rows

Add these three books: (1, 'Dune', 'Frank Herbert', 1965), (2, 'Emma', 'Jane Austen', 1815) and (3, 'Ulysses', 'James Joyce', 1922).

Step 2.3 — SELECT data

Select only the title column. Then try SELECT * and compare.

Expected result:

title
Dune
Emma
Ulysses

Step 2.4 — ALTER the table

Add a new column rating of type REAL. Then run SELECT * FROM books;. What value do the existing rows have in the new column?

Expected result:

id | title | author | year | rating
1 | Dune | Frank Herbert | 1965 | NULL
2 | Emma | Jane Austen | 1815 | NULL
3 | Ulysses | James Joyce | 1922 | NULL

Step 2.5 — UPDATE a row

Give the book with id 2 (Emma) the rating 4.5. Then check the table.

Expected result:

id | title | author | year | rating
1 | Dune | Frank Herbert | 1965 | NULL
2 | Emma | Jane Austen | 1815 | 4.5
3 | Ulysses | James Joyce | 1922 | NULL
Tip: Never forget the WHERE clause: without it every row would get the rating 4.5.

Step 2.6 — DELETE rows

Delete every book that has no rating (its rating is NULL). Then check the table.

Expected result:

id | title | author | year | rating
2 | Emma | Jane Austen | 1815 | 4.5

Step 2.7 — Constraints

Create a table members with: id INTEGER PRIMARY KEY, email TEXT UNIQUE, name TEXT NOT NULL and country TEXT with the default value 'Belgium'. Insert one member (1, 'ana@example.com', 'Ana') without giving a country, and check that the default was used. Then try (do not worry about the error messages) to insert a second member with the same id, and one without a name: what happens?

Expected result:

id | email | name | country
1 | ana@example.com | Ana | Belgium
