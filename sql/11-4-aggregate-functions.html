4. Aggregate Functions

So far we have retrieved rows. Now we will perform calculations with SQL. Calculations performed on multiple rows of a table are called aggregates: they combine many rows into a single, more meaningful value.

Open fake_apps.db and look at the table:

SELECT * FROM fake_apps;
Dataset: open fake_apps.db, table fake_apps — columns: id, name, category, downloads, price.

4.1 COUNT

COUNT() counts the number of rows.

SELECT COUNT(*)
FROM fake_apps;

4.2 SUM

SUM() adds up the values of a column.

SELECT SUM(downloads)
FROM fake_apps;

4.3 MAX and MIN

MAX() returns the largest value of a column, MIN() the smallest.

SELECT MAX(downloads)
FROM fake_apps;

4.4 AVG

AVG() returns the average of the values in a column.

SELECT AVG(downloads)
FROM fake_apps;

4.5 ROUND

ROUND(column, n) rounds the values to n decimal places.

SELECT ROUND(price, 0)
FROM fake_apps;

4.6 GROUP BY

Grouping based on a column

Often we want an aggregate for data with certain characteristics. For example, in the movie database we might want the mean IMDb rating for each year. We could write one query per year…

SELECT AVG(imdb_rating) FROM movie WHERE year = 1999;
SELECT AVG(imdb_rating) FROM movie WHERE year = 2000;
SELECT AVG(imdb_rating) FROM movie WHERE year = 2001;
-- ...and so on

Luckily, there is a better way. GROUP BY arranges identical data into groups and is used together with aggregate functions:

SELECT year,
   AVG(imdb_rating)
FROM movie
GROUP BY year
ORDER BY year;
Important: GROUP BY comes after any WHERE, but before ORDER BY or LIMIT.

Grouping based on a calculation

Sometimes we group by a calculation done on a column. For example, how many movies have ratings that round to 1, 2, 3, 4 or 5?

SELECT ROUND(imdb_rating),
   COUNT(name)
FROM movie
GROUP BY ROUND(imdb_rating)
ORDER BY ROUND(imdb_rating);

This is long and error-prone. SQL lets you use column reference numbers instead: 1 is the first selected column, 2 the second, and so on. The following query is equivalent:

SELECT ROUND(imdb_rating),
   COUNT(name)
FROM movie
GROUP BY 1
ORDER BY 1;

4.7 HAVING

GROUP BY forms groups; HAVING decides which groups to keep. Imagine we want the number of movies of each genre produced each year, but only for combinations that have more than three movies. We cannot use WHERE, because we are not filtering rows — we are filtering groups.

SELECT year,
   genre,
   COUNT(name)
FROM movie
GROUP BY 1, 2
HAVING COUNT(name) > 3;

HAVING is very similar to WHERE: every type of condition you learned for WHERE also works in HAVING. It always comes after GROUP BY and before ORDER BY and LIMIT.

Limits the results based on values of individual rows.Limits the results based on an aggregate property (a group).
Runs before grouping.Runs after GROUP BY.
