Project 1: Celebrities

Download emptyDb.db · Open SQLite Online

Practice every statement from the Manipulation chapter. Open emptyDb.db in the online editor first.

  1. Create the table celebs with three columns: id (INTEGER), name (TEXT) and age (INTEGER).
  2. Add four celebrities: Justin Bieber (23, id 1), Beyonce Knowles (34, id 2), Jeremy Lin (27, id 3) and Taylor Swift (27, id 4).
  3. Use a SELECT to retrieve all the names from celebs.
  4. Add a new column twitter_handle to the table.
  5. Update the table to include Taylor Swift's handle: @taylorswift13.
  6. Delete all rows that have a NULL value in the Twitter handle column.
  7. Create a new table awards with constraints: id is an INTEGER and the PRIMARY KEY; recipient is TEXT and NOT NULL; award_name is TEXT with the default value Grammy.
Tip: After each change, run SELECT * FROM celebs; to check the result. Copy each finished query into your own notes, then erase it from the editor before writing the next one.
