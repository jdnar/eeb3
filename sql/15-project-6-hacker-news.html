Project 6: Hacker News

On this page
  • Do a few users dominate Hacker News?
  • Which sites feed Hacker News?
  • What is the best time to post a story?

Hacker News is a popular website run by Y Combinator, widely known in the tech industry as a community site for sharing news, showing off projects and asking questions. You will work with a table named hacker_news that contains stories since its launch in 2007 (data made public under the MIT license). Open hackerNews.db.

Dataset: open hackerNews.db, table hacker_news — columns: title (title of the story), user (who submitted it), score, timestamp, url.
  1. What are the top five stories with the highest scores?

Do a few users dominate Hacker News?

Studies suggest online forums are dominated by a small share of users (the "1-9-90 rule"). Is a small percentage of submitters taking the majority of the points?

  • Find the total score of all stories.
  • Find the individual users whose combined scores are more than 200, and show their combined scores. (GROUP BY and HAVING are needed.)
  • Some users are "rickrolling": tricking readers into clicking a link to a funny video while claiming it is about coding. The video URL is https://www.youtube.com/watch?v=dQw4w9WgXcQ. How many times has each offending user posted this link?
Note: If you add the scores of the power users from the second query and divide by the total from the first, you know how dominant these users are.

Which sites feed Hacker News?

Stories are essentially links to other websites. Which feeds Hacker News the most: GitHub, Medium or the New York Times?

First categorize each story by source with a CASE statement. Fill in the other WHEN branches and the ELSE:

SELECT CASE
   WHEN url LIKE '%github.com%' THEN 'GitHub'
   -- WHEN statement here
   -- WHEN statement here
   -- ELSE statement here
  END AS 'Source'
FROM hacker_news;

Then build on it: add a column with the number of stories from each source using COUNT(), and GROUP BY the CASE statement (remember you can refer to a column by its number).

What is the best time to post a story?

Every submitter wants a high score so the story reaches the front page. What is the best time of day to post? First look at the format of the timestamp column:

SELECT timestamp
FROM hacker_news
LIMIT 10;

Values look like 2018-05-08T12:30:00Z. Ignoring the T and Z, the format is YYYY-MM-DD HH:MM:SS.

SQLite provides the powerful strftime(format, column) function, which returns a formatted date. Test it:

SELECT timestamp,
   strftime('%H', timestamp)
FROM hacker_news
GROUP BY 1
LIMIT 20;

Now write a query that returns three columns: the hour of the timestamp, the average score for each hour, and the count of stories for each hour. Then improve it: round the average scores with ROUND(), rename the columns with AS, and add a WHERE clause to filter out NULL timestamps. What are the best hours to post?
