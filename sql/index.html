This course takes you from your very first SQL statement to queries that combine several tables. Every chapter has the same rhythm: a short piece of theory, runnable examples, and a hands-on project. Solutions to all projects are collected in the appendix at the end — try each exercise yourself first.

Tools you need

  • A web browser and the online editor SQLite Online (https://sqliteonline.com/). Use File > Open DB to load a database file.
  • The practice database files used in the course: myFirstDb.db, emptyDb.db, movie.db, nomnom.db, fake_apps.db, startup.db, hackerNews.db, multiples.db and lyft.db. In the original course these are provided by the teacher in a folder called ClassesICT.
Important: If you do not have the .db files, you can still follow every chapter: create the tables yourself with CREATE TABLE and INSERT, using the column names listed in each exercise.

Good habits when using the online editor

  • Erase the previous query before writing a new one. Otherwise, pressing Run executes the old statement again — a problem for statements that should run only once, such as CREATE TABLE or INSERT.
  • After every change to a table, run SELECT * FROM table_name; to check the result.
  • The editor keeps a history of your queries (bottom-right button, then History).
