Tip: Type every statement yourself and run it after each step. Solutions: Appendix B.3.

Set up your practice database

The next three warm-ups (Chapters 3, 4 and 5) use two small tables, pets and owners, so you do not need any external file. In a new empty database, run this script once:

CREATE TABLE pets (id INTEGER PRIMARY KEY, name TEXT, species TEXT, age INTEGER, weight REAL, owner_id INTEGER);
INSERT INTO pets VALUES (1, 'Rex', 'dog', 4, 18.5, 1);
INSERT INTO pets VALUES (2, 'Mia', 'cat', 2, 4.1, 2);
INSERT INTO pets VALUES (3, 'Bubbles', 'fish', 1, 0.1, NULL);
INSERT INTO pets VALUES (4, 'Luna', 'cat', 7, 5.0, 1);
INSERT INTO pets VALUES (5, 'Max', 'dog', 9, 25.2, 3);
INSERT INTO pets VALUES (6, 'Coco', 'bird', 3, 0.4, 2);
INSERT INTO pets VALUES (7, 'Rocky', 'dog', 2, 12.0, NULL);
INSERT INTO pets VALUES (8, 'Tom', 'cat', 5, 4.8, 3);

CREATE TABLE owners (id INTEGER PRIMARY KEY, name TEXT, city TEXT);
INSERT INTO owners VALUES (1, 'Ana', 'Brussels');
INSERT INTO owners VALUES (2, 'Luis', 'Madrid');
INSERT INTO owners VALUES (3, 'Sofia', 'Brussels');
INSERT INTO owners VALUES (4, 'Omar', 'Paris');
Note: pets.owner_id points to owners.id. Two pets (Bubbles and Rocky) have no owner, and one owner (Omar) has no pet — this will be useful in Chapter 5.

Run SELECT * FROM pets; to see the 8 pets and SELECT * FROM owners; to see the 4 owners.

Step 3.1 — SELECT columns

Select only the name and species columns of all pets.

Expected result:

name | species
Rex | dog
Mia | cat
Bubbles | fish
Luna | cat
Max | dog
Coco | bird
Rocky | dog
Tom | cat

Step 3.2 — AS

Select the name column but display it with the heading Pet name.

Expected result:

Pet name
Rex
Mia
Bubbles
Luna
Max
Coco
Rocky
Tom

Step 3.3 — DISTINCT

List each species only once.

Expected result:

species
dog
cat
fish
bird

Step 3.4 — WHERE

Show the name and age of the pets older than 5.

Expected result:

name | age
Luna | 7
Max | 9

Step 3.5 — LIKE

Show the pets whose name starts with the letter M. Then try 'R_x' as a pattern: which pet matches?

Expected result:

name
Mia
Max

Step 3.6 — IS NULL

Show the names of the pets that have no owner.

Expected result:

name
Bubbles
Rocky

Step 3.7 — BETWEEN

Show the name and age of the pets aged between 2 and 4 years (both included).

Expected result:

name | age
Rex | 4
Mia | 2
Coco | 3
Rocky | 2

Step 3.8 — AND

Show the names of the dogs younger than 5.

Expected result:

name
Rex
Rocky

Step 3.9 — OR

Show the names of the pets that are fish or birds.

Expected result:

name
Bubbles
Coco

Step 3.10 — ORDER BY

Show the name and weight of all pets, from the heaviest to the lightest.

Expected result:

name | weight
Max | 25.2
Rex | 18.5
Rocky | 12.0
Luna | 5.0
Tom | 4.8
Mia | 4.1
Coco | 0.4
Bubbles | 0.1

Step 3.11 — LIMIT

Show the three oldest pets (name and age).

Expected result:

name | age
Max | 9
Luna | 7
Tom | 5

Step 3.12 — CASE

Show each pet's name and a column size: 'Large' if the weight is above 15, 'Medium' if it is above 3, and 'Small' in all other cases.

Expected result:

name | size
Rex | Large
Mia | Medium
Bubbles | Small
Luna | Medium
Max | Large
Coco | Small
Rocky | Medium
Tom | Medium
