Project 2: Friends

Download emptyDb.db · Open SQLite Online

Open emptyDb.db again and build a small address book.

  1. Create a table friends with three columns: id (INTEGER), name (TEXT) and birthday (DATE).
  2. Add Ororo Munroe, born on May 30th, 1940. Remember the date format YYYY-MM-DD.
  3. Add two of your own friends, each with an id, a name and a birthday.
  4. Ororo realizes she can control the weather and changes her name to Storm. Update her record.
  5. Add a new column named email.
  6. Update the email address of everyone in the table. Storm's email is storm@eursc.eu.
  7. Storm is fictional… remove her from friends.
  8. Check the final result with SELECT * FROM friends;.
Tip: After step 2, run SELECT * FROM friends; and check two things: was the table created, and was Ororo added?
