Project 5: Startups

On this page
  • Warm-up
  • Valuations among different sectors
  • What are the most competitive markets?
  • Startup size by location

It is your first day as a TechCrunch reporter and you must write an article on rising trends in the startup world. Your boss gave you a database with a table of some of the biggest names in the industry. Write aggregate queries to find interesting insights. Open startup.db and run SELECT * FROM startup;.

Dataset: open startup.db, table startup — columns: name, location, category, employees, raised, valuation, founded, stage, ceo, info.

Warm-up

  1. Calculate the total number of companies in the table.
  2. Calculate the total value of all companies by taking the SUM() of the valuation column.
  3. What is the highest amount raised by a startup?
  4. Edit the query to return the maximum amount raised during the Seed stage.
  5. In what year was the oldest company on the list founded?

Valuations among different sectors

  • Return the average valuation.
  • Return the average valuation in each category.
  • Do the same, rounding the averages to two decimal places.
  • Do the same again, and order the list from highest to lowest average.

What are the most competitive markets?

  • Return the name of each category with the total number of companies that belong to it.
  • Filter the result to include only categories with more than three companies. These are the most competitive markets.

Startup size by location

  • What is the average size (number of employees) of a startup in each location?
  • Show only the locations whose average size is above 500.
