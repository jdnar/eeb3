Project 3: Movies

Use the same movie database as in the theory to answer these questions.

  1. Return the unique values of the year column.
  2. Retrieve all the movies released after 2014. Select all the columns using *.
  3. Select all the information about movie titles that begin with the word The. (You might need a space in there!)
  4. Find all the movies without an IMDb rating. Select only the name column.
  5. Using BETWEEN, select all information about movies released in the 1970s.
  6. A picky friend only wants to watch old horror films. Using AND, select all movies made before 1985 that are in the horror genre.
  7. Using OR, return all movies that are either a romance or a comedy.
  8. Retrieve the name, year and imdb_rating of all movies, ordered from highest to lowest rating.
  9. Combining LIMIT and ORDER BY, return the top 3 highest-rated movies. Select all columns.
  10. Select the name column and use a CASE statement to create a second column: 'Chill' if the genre is romance or comedy, and 'Intense' in all other cases. Optionally rename the whole CASE column to Mood using AS.
