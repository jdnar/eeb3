6. Summary

On this page
  • Manipulation
  • Queries
  • Aggregate functions
  • Multiple tables

SQL is a programming language designed to manipulate and manage data stored in relational databases. A relational database organizes information into one or more tables, and a table is a collection of data organized into rows and columns.

Manipulation

A statement is a string of characters that the database recognizes as a valid command.

CommandPurpose
CREATE TABLECreates a new table
INSERT INTOAdds a new row to a table
SELECTQueries data from a table
ALTER TABLEChanges an existing table
UPDATEEdits a row in a table
DELETE FROMDeletes rows from a table
ConstraintsAdd information about how a column can be used (PRIMARY KEY, UNIQUE, NOT NULL, DEFAULT)

Queries

ClausePurpose
SELECTThe clause used every time you query information from a database
ASRenames a column or table
DISTINCTReturns unique values
WHEREFilters the results based on conditions you specify
LIKE, BETWEENSpecial operators (pattern matching and ranges)
AND, ORCombine multiple conditions
ORDER BYSorts the result
LIMITMaximum number of rows the query returns
CASECreates different outputs
_ and %_ represents one character; % represents as many characters as you want

Aggregate functions

Aggregate functions combine multiple rows into a single value of more meaningful information.

Function / clausePurpose
COUNT()Counts the number of rows
SUM()Sum of the values in a column
MAX() / MIN()Largest / smallest value
AVG()Average of the values in a column
ROUND()Rounds the values in a column
GROUP BYUsed with aggregate functions to combine data from one or more columns
HAVINGLimits the results of a query based on an aggregate property

Multiple tables

ConceptMeaning
JOINCombines rows from different tables when the join condition is true
LEFT JOINReturns every row of the left table; where the condition is not met, NULL fills the right table's columns
Primary keyA column that serves as a unique identifier for the rows of a table
Foreign keyA column that contains the primary key of another table
CROSS JOINCombines all rows of one table with all rows of another
UNIONStacks one dataset on top of another
WITHDefines one or more temporary tables that can be used in the final query
