One of the core purposes of SQL is to retrieve information stored in a database. This is called querying. A query asks the database a question and returns a result set with the data that answers it.

In this chapter you will query a database with a single table named movie. Open movie.db and run:

SELECT * FROM movie;
Dataset: open movie.db, table movie — columns: id, name, genre, year, imdb_rating.

Try each of the following commands in the editor and observe what they do.

3.1 SELECT

Select only the columns you need by listing them, separated by commas.

SELECT name, genre
FROM movie;

3.2 AS

AS renames a column (or table) in the result. It does not change the database itself — only the name displayed.

SELECT name AS 'Titles'
FROM movie;

3.3 DISTINCT

DISTINCT returns only unique values, filtering out duplicates.

SELECT DISTINCT genre
FROM movie;

3.4 WHERE

WHERE filters the result using a condition, so you only get the rows you care about.

SELECT *
FROM movie
WHERE imdb_rating > 8;

Comparison operators you can use: =, !=, >, <, >=, <=.

3.5 LIKE

LIKE searches for a pattern in a column. Two wildcards are available:

  • _ stands for exactly one character.
  • % stands for any number of characters (including none).
-- Matches 'Se_en' with any single character in the middle (e.g. Seven)
SELECT *
FROM movie
WHERE name LIKE 'Se_en';

-- Matches every title that starts with A
SELECT *
FROM movie
WHERE name LIKE 'A%';

3.6 IS NULL

A missing value is NULL. You cannot test it with =; use IS NULL or IS NOT NULL.

SELECT name
FROM movie
WHERE imdb_rating IS NOT NULL;

3.7 BETWEEN

BETWEEN filters a value within a range. The limits are included.

SELECT *
FROM movie
WHERE year BETWEEN 1990 AND 1999;

3.8 AND

AND combines conditions: all of them must be true.

SELECT *
FROM movie
WHERE year BETWEEN 1990 AND 1999
   AND genre = 'romance';

3.9 OR

OR combines conditions: at least one must be true.

SELECT *
FROM movie
WHERE year > 2014
   OR genre = 'action';

3.10 ORDER BY

ORDER BY sorts the result. The default order is ascending (ASC); use DESC for descending.

SELECT *
FROM movie
ORDER BY name DESC;

3.11 LIMIT

LIMIT sets the maximum number of rows returned. Combined with ORDER BY it gives you "top N" lists.

SELECT *
FROM movie
LIMIT 10;

3.12 CASE

CASE creates different outputs depending on conditions — SQL's version of if / else if / else. Conditions are checked in order and the first one that is true wins.

SELECT name,
CASE
  WHEN imdb_rating > 8 THEN 'Fantastic'
  WHEN imdb_rating > 6 THEN 'Poorly Received'
  ELSE 'Avoid at All Costs'
END AS 'Review'
FROM movie;

3.13 Clause order

When you combine clauses, SQL expects them in this order:

SELECT  columns
FROM    table
WHERE   row conditions
GROUP BY ...        -- chapter 4
HAVING  ...         -- chapter 4
ORDER BY column
LIMIT   number;
