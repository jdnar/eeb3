Exercise 1

  1. Using fake_apps, run the query below. What do you expect the result to be?
SELECT price, COUNT(*)
FROM fake_apps
GROUP BY price;
  • Add a WHERE clause to count the total number of apps downloaded more than 20,000 times, at each price.
  • Write a new query that calculates the total number of downloads for each category. Select category and SUM(downloads).

Exercise 2

Rewrite the query below using column reference numbers instead of column names after GROUP BY:

SELECT category,
   price,
   AVG(downloads)
FROM fake_apps
GROUP BY category, price;

Exercise 3

The query below returns the (rounded) average downloads and the number of apps at each price point. Some price points have very few apps, so their averages are less meaningful. Add a HAVING clause that keeps only price points with more than 10 apps.

SELECT price,
   ROUND(AVG(downloads)),
   COUNT(*)
FROM fake_apps
GROUP BY price;
